    Gráficas de funciones cuadráticas

    Determine las coordenadas del vértice, intersecciones con los ejes \(x\) e \(y\), recorrido y elabore un gráfico de las siguientes funciones cuadráticas.

    Problema 1:
    \[ f(x) = x^2 - 4x + 3 \]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-(-4)}{2(1)} = 2\). \(y_v = f(2) = (2)^2 - 4(2) + 3 = -1\). \(\Rightarrow V(2, -1)\)
    • Intersección eje \(y\): \(f(0) = 3 \Rightarrow (0, 3)\)
    • Intersecciones eje \(x\): \(x^2 - 4x + 3 = 0\) \((x-3)(x-1) = 0 \Rightarrow x_1 = 1, x_2 = 3\). Puntos: \((1,0), (3,0)\)
    • Recorrido: Como \(a = 1 > 0\), la parábola abre hacia arriba. \(\text{Rec} = [-1, \infty)\)
    Problema 2:
    \[f(x) = -x^2 + 2x + 8\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-2}{2(-1)} = 1\). \(y_v = f(1) = -(1)^2 + 2(1) + 8 = 9\). \(\Rightarrow V(1, 9)\)
    • Intersección eje \(y\): \(f(0) = 8 \Rightarrow (0, 8)\)
    • Intersecciones eje \(x\): \(-x^2 + 2x + 8 = 0\) \(x^2 - 2x - 8 = 0 \Rightarrow (x-4)(x+2) = 0\). Puntos: \((-2,0), (4,0)\)
    • Recorrido: Como \(a = -1 < 0\), abre hacia abajo. \(\text{Rec} = (-\infty, 9]\)
    Problema 3:
    \[f(x) = x^2 - 9\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-0}{2(1)} = 0\). \(y_v = f(0) = -9\). \(\Rightarrow V(0, -9)\)
    • Intersección eje \(y\): \((0, -9)\) (Coincide con el vértice)
    • Intersecciones eje \(x\): \(x^2 - 9 = 0 \Rightarrow x^2 = 9\) \(x = \pm 3\). Puntos: \((-3,0), (3,0)\)
    • Recorrido: \(a = 1 > 0\). \(\text{Rec} = [-9, \infty)\)
    Problema 4:
    \[f(x) = -x^2 + 6x - 5\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-6}{2(-1)} = 3\). \(y_v = f(3) = -(3)^2 + 6(3) - 5 = 4\). \(\Rightarrow V(3, 4)\)
    • Intersección eje \(y\): \(f(0) = -5 \Rightarrow (0, -5)\)
    • Intersecciones eje \(x\): \(-x^2 + 6x - 5 = 0\) \(x^2 - 6x + 5 = 0 \Rightarrow (x-5)(x-1) = 0\). Puntos: \((1,0), (5,0)\)
    • Recorrido: \(a = -1 < 0\). \(\text{Rec} = (-\infty, 4]\)
    Problema 5:
    \[f(x) = x^2 + 4x + 4\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-4}{2(1)} = -2\). \(y_v = f(-2) = (-2)^2 + 4(-2) + 4 = 0\). \(\Rightarrow V(-2, 0)\)
    • Intersección eje \(y\): \(f(0) = 4 \Rightarrow (0, 4)\)
    • Intersecciones eje \(x\): \(x^2 + 4x + 4 = 0\) \((x+2)^2 = 0 \Rightarrow x = -2\). Punto: \((-2,0)\) (Un sólo punto de corte, toca el eje).
    • Recorrido: \(a = 1 > 0\). \(\text{Rec} = [0, \infty)\)
    Problema 6:
    \[f(x) = 2x^2 - 4x - 6\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-(-4)}{2(2)} = 1\). \(y_v = f(1) = 2(1)^2 - 4(1) - 6 = -8\). \(\Rightarrow V(1, -8)\)
    • Intersección eje \(y\): \(f(0) = -6 \Rightarrow (0, -6)\)
    • Intersecciones eje \(x\): \(2(x^2 - 2x - 3) = 0\) \(x^2 - 2x - 3 = 0 \Rightarrow (x-3)(x+1) = 0\). Puntos: \((-1,0), (3,0)\)
    • Recorrido: \(a = 2 > 0\). \(\text{Rec} = [-8, \infty)\)
    Problema 7:
    \[f(x) = -3x^2 + 12x - 12\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-12}{2(-3)} = 2\). \(y_v = f(2) = -3(4) + 12(2) - 12 = 0\). \(\Rightarrow V(2, 0)\)
    • Intersección eje \(y\): \(f(0) = -12 \Rightarrow (0, -12)\)
    • Intersecciones eje \(x\): \(-3(x^2 - 4x + 4) = 0\) \(-3(x-2)^2 = 0 \Rightarrow x = 2\). Punto: \((2,0)\)
    • Recorrido: \(a = -3 < 0\). \(\text{Rec} = (-\infty, 0]\)
    Problema 8:
    \[f(x) = \frac{1}{2}x^2 - 2x + 4\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-(-2)}{2(1/2)} = \frac{2}{1} = 2\). \(y_v = f(2) = \frac{1}{2}(4) - 2(2) + 4 = 2\). \(\Rightarrow V(2, 2)\)
    • Intersección eje \(y\): \(f(0) = 4 \Rightarrow (0, 4)\)
    • Intersecciones eje \(x\): \(\Delta = (-2)^2 - 4(\frac{1}{2})(4) = 4 - 8 = -4\). Como \(\Delta < 0\), no tiene raíces reales. Puntos: Ninguno (no corta al eje \(x\)).
    • Recorrido: \(a = 1/2 > 0\). \(\text{Rec} = [2, \infty)\)
    Problema 9:
    \[f(x) = -2x^2 - 4x - 5\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-(-4)}{2(-2)} = \frac{4}{-4} = -1\). \(y_v = f(-1) = -2(1) - 4(-1) - 5 = -3\). \(\Rightarrow V(-1, -3)\)
    • Intersección eje \(y\): \(f(0) = -5 \Rightarrow (0, -5)\)
    • Intersecciones eje \(x\): \(\Delta = (-4)^2 - 4(-2)(-5) = 16 - 40 = -24\). \(\Delta < 0 \Rightarrow\) No corta al eje \(x\).
    • Recorrido: \(a = -2 < 0\). \(\text{Rec} = (-\infty, -3]\)
    Problema 10:
    \[f(x) = 3x^2 - 5x + 2\]
    Ver Desarrollo
    • Vértice: \(x_v = \frac{-(-5)}{2(3)} = \frac{5}{6}\). \(y_v = f(\frac{5}{6}) = 3(\frac{25}{36}) - \frac{25}{6} + 2 = -\frac{1}{12}\). \(\Rightarrow V(\frac{5}{6}, -\frac{1}{12})\)
    • Intersección eje \(y\): \(f(0) = 2 \Rightarrow (0, 2)\)
    • Intersecciones eje \(x\): \((3x-2)(x-1) = 0\) \(x_1 = \frac{2}{3}, x_2 = 1\). Puntos: \(\left(\frac{2}{3}, 0\right), (1, 0)\)
    • Recorrido: \(a = 3 > 0\). \(\text{Rec} = \left[-\frac{1}{12}, \infty\right)\)
