    Valor Absoluto

    Ecuaciones e inecuaciones con valor absoluto.

    Definiciones Básicas

    Recordemos que el valor absoluto de un número \(x\), denotado por \(|x|\), representa su distancia al origen y se define como: $\(|x| = \begin{cases} x & \text{si } x \geq 0 \\ -x & \text{si } x < 0 \end{cases}\)$

    Problema 1: Ecuación Simple

    Resuelva \(|3x + 1| = 2\).

    Ver Desarrollo

    Por propiedad, \(|u| = a \iff u = a \vee u = -a\). 1. \(3x + 1 = 2 \implies 3x = 1 \implies x = 1/3\) 2. \(3x + 1 = -2 \implies 3x = -3 \implies x = -1\)

    Solución: \(S = \{-1, 1/3\}\).

    Problema 2: Ecuación con Variable en el Segundo Miembro

    Resuelva \(|2x - 1| = 3x + 1\).

    Ver Desarrollo

    Para que tenga solución, debe cumplirse que \(3x + 1 \geq 0 \implies x \geq -1/3\). 1. \(2x - 1 = 3x + 1 \implies -x = 2 \implies x = -2\) 2. \(2x - 1 = -(3x + 1) \implies 2x - 1 = -3x - 1 \implies 5x = 0 \implies x = 0\)

    Validación: \(x = -2\) no cumple la condición \(x \geq -1/3\). \(x = 0\) sí la cumple.

    Solución: \(S = \{0\}\).

    Problema 3: Suma de Valores Absolutos

    Resuelva \(|x - 1| + |3x - 2| = 4\).

    Ver Desarrollo

    Debemos analizar por tramos según los puntos críticos \(x=1\) y \(x=2/3\): 1. Tramo \(x < 2/3\): \(-(x-1) - (3x-2) = 4 \implies -4x + 3 = 4 \implies x = -1/4\) (Válido). 2. Tramo \(2/3 \leq x < 1\): \(-(x-1) + (3x-2) = 4 \implies 2x - 1 = 4 \implies x = 5/2\) (No cae en el tramo). 3. Tramo \(x \geq 1\): \((x-1) + (3x-2) = 4 \implies 4x - 3 = 4 \implies x = 7/4\) (Válido).

    Solución: \(S = \{-1/4, 7/4\}\).

    Problema 4: Valor Absoluto Anidado

    Resuelva \(||x - 1| - 2| = 5\).

    Ver Desarrollo
    1. \(|x - 1| - 2 = 5 \implies |x - 1| = 7\)
    2. \(x - 1 = 7 \implies x = 8\)
    3. \(x - 1 = -7 \implies x = -6\)
    4. \(|x - 1| - 2 = -5 \implies |x - 1| = -3\) (Imposible, el valor absoluto no es negativo).

    Solución: \(S = \{-6, 8\}\).

    Problema 5: Inecuación "Mayor que"

    Resuelva \(|x - 3| > 5\).

    Ver Desarrollo

    Propiedad: \(|u| > a \iff u > a \vee u < -a\). 1. \(x - 3 > 5 \implies x > 8\) 2. \(x - 3 < -5 \implies x < -2\)

    Solución: \(S = ]-\infty, -2[ \cup ]8, +\infty[\).

    Problema 6: Inecuación "Menor o igual que"

    Resuelva \(|x + 1| \leq 3\).

    Ver Desarrollo

    Propiedad: \(|u| \leq a \iff -a \leq u \leq a\). $\(-3 \leq x + 1 \leq 3\)$ Restando 1: \(-4 \leq x \leq 2\).

    Solución: \(S = [-4, 2]\).

    Problema 7: Inecuación Fraccionaria

    Resuelva \(\left| \dfrac{2x + 1}{3} \right| < 4\).

    Ver Desarrollo

    $\(-4 < \frac{2x + 1}{3} < 4\)$ Multiplicando por 3: \(-12 < 2x + 1 < 12\). Restando 1: \(-13 < 2x < 11\). Dividiendo por 2: \(-6.5 < x < 5.5\).

    Solución: \(S = ]-13/2, 11/2[\).

    Problema 8: Inecuación Lineal

    Resuelva \(|5x - 2| < 4\).

    Ver Desarrollo
    \[-4 < 5x - 2 < 4$$ $$-2 < 5x < 6$$ $$-2/5 < x < 6/5\]

    Solución: \(S = ]-0.4, 1.2[\).

    Problema 9: Inecuación "Mayor que" Simple

    Resuelva \(|2x + 3| > 2\).

    Ver Desarrollo
    1. \(2x + 3 > 2 \implies 2x > -1 \implies x > -1/2\)
    2. \(2x + 3 < -2 \implies 2x < -5 \implies x < -5/2\)

    Solución: \(S = ]-\infty, -5/2[ \cup ]-1/2, +\infty[\).
