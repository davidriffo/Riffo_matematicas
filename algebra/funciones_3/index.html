    Problema 1: Considere la función polinomial \(f:\mathbb{R}\to \mathbb{R}\) dada por:

    \[f(x) = 2x^2 - 5x + 3\]

    Calcule:

    a) \(f(1) + f(0) - 2f(-1)\)

    b) \(-f(2) + (f(3))^2\)

    c) \(\dfrac{f(4) - f(-2)}{3}\)

    d) \((f(2) - f(0) + f(1))^2\)

    Ver Desarrollo

    Primero, evaluamos la función en los valores necesarios: * \(f(0) = 2(0)^2 - 5(0) + 3 = 3\)

    • \(f(1) = 2(1)^2 - 5(1) + 3 = 2 - 5 + 3 = 0\)

    • \(f(-1) = 2(-1)^2 - 5(-1) + 3 = 2 + 5 + 3 = 10\)

    • \(f(2) = 2(2)^2 - 5(2) + 3 = 8 - 10 + 3 = 1\)

    • \(f(3) = 2(3)^2 - 5(3) + 3 = 18 - 15 + 3 = 6\)

    • \(f(4) = 2(4)^2 - 5(4) + 3 = 32 - 20 + 3 = 15\)

    • \(f(-2) = 2(-2)^2 - 5(-2) + 3 = 8 + 10 + 3 = 21\)

    Ahora, resolvemos cada expresión: a) $\(f(1) + f(0) - 2f(-1) = 0 + 3 - 2(10) = 3 - 20 = -17\)$

    b) $\(-f(2) + (f(3))^2 = -1 + (6)^2 = -1 + 36 = 35\)$

    c) $\(\dfrac{f(4) - f(-2)}{3} = \dfrac{15 - 21}{3} = \dfrac{-6}{3} = -2\)$

    d) $\((f(2) - f(0) + f(1))^2 = (1 - 3 + 0)^2 = (-2)^2 = 4\)$

    Problema 2: Considere la función racional \(g:\mathbb{R}-\{-2\}\to \mathbb{R}\) dada por:

    \[g(x) = \frac{3x - 1}{x + 2}\]

    Calcule:

    a) \(g(1) + 2g(0) - g(-1)\)

    b) \(-g(2) + (g(-3))^2\)

    c) \(\dfrac{g(3) - g(0)}{g(-1)}\)

    d) \((g(1) - g(-3) + g(0))^2\)

    Ver Desarrollo

    Evaluamos la función en los puntos requeridos: * \(g(0) = \frac{0 - 1}{0 + 2} = -\frac{1}{2}\)

    • \(g(1) = \frac{3(1) - 1}{1 + 2} = \frac{2}{3}\)

    • \(g(-1) = \frac{3(-1) - 1}{-1 + 2} = \frac{-4}{1} = -4\)

    • \(g(2) = \frac{3(2) - 1}{2 + 2} = \frac{5}{4}\)

    • \(g(-3) = \frac{3(-3) - 1}{-3 + 2} = \frac{-10}{-1} = 10\)

    • \(g(3) = \frac{3(3) - 1}{3 + 2} = \frac{8}{5}\)

    Resolvemos: a) $\(g(1) + 2g(0) - g(-1) = \frac{2}{3} + 2\left(-\frac{1}{2}\right) - (-4) = \frac{2}{3} - 1 + 4 = 3 + \frac{2}{3} = \frac{11}{3}\)$

    b) $\(-g(2) + (g(-3))^2 = -\frac{5}{4} + (10)^2 = -\frac{5}{4} + 100 = \frac{395}{4}\)$

    c) $\(\dfrac{g(3) - g(0)}{g(-1)} = \dfrac{\frac{8}{5} - \left(-\frac{1}{2}\right)}{-4} = \dfrac{\frac{16 + 5}{10}}{-4} = \dfrac{21/10}{-4} = -\frac{21}{40}\)$

    d) $\((g(1) - g(-3) + g(0))^2 = \left(\frac{2}{3} - 10 - \frac{1}{2}\right)^2 = \left(\frac{4 - 60 - 3}{6}\right)^2 = \left(-\frac{59}{6}\right)^2 = \frac{3481}{36}\)$

    Problema 3: Considere la función definida por tramos \(h:\mathbb{R}\to \mathbb{R}\) dada por:

    \[h(x) = \begin{cases} 3x + 1 & \text{si } x < 1 \\ x^2 - 2 & \text{si } x \ge 1 \end{cases}\]

    Calcule:

    a) \(h(0) + h(2) - 2h(1)\)

    b) \(-h(-2) + (h(3))^2\)

    c) \(\dfrac{h(4) - h(-1)}{2}\)

    d) \((h(2) - h(0) + h(-3))^2\)

    Ver Desarrollo

    Evaluamos prestando atención al tramo correspondiente: * \(x=0 < 1 \implies h(0) = 3(0) + 1 = 1\)

    • \(x=1 \ge 1 \implies h(1) = 1^2 - 2 = -1\)

    • \(x=2 \ge 1 \implies h(2) = 2^2 - 2 = 2\)

    • \(x=-1 < 1 \implies h(-1) = 3(-1) + 1 = -2\)

    • \(x=-2 < 1 \implies h(-2) = 3(-2) + 1 = -5\)

    • \(x=-3 < 1 \implies h(-3) = 3(-3) + 1 = -8\)

    • \(x=3 \ge 1 \implies h(3) = 3^2 - 2 = 7\)

    • \(x=4 \ge 1 \implies h(4) = 4^2 - 2 = 14\)

    Resolvemos: a) $\(h(0) + h(2) - 2h(1) = 1 + 2 - 2(-1) = 3 + 2 = 5\)$

    b) $\(-h(-2) + (h(3))^2 = -(-5) + (7)^2 = 5 + 49 = 54\)$

    c) $\(\dfrac{h(4) - h(-1)}{2} = \dfrac{14 - (-2)}{2} = \dfrac{16}{2} = 8\)$

    d) $\((h(2) - h(0) + h(-3))^2 = (2 - 1 - 8)^2 = (-7)^2 = 49\)$

    Problema 4: Considere la función con valor absoluto \(p:\mathbb{R}\to \mathbb{R}\) dada por:

    \[p(x) = |2x - 5| - 3x\]

    Calcule:

    a) \(p(1) + 3p(3) - p(0)\)

    b) \(-p(4) + (p(2))^2\)

    c) \(\dfrac{p(-1) - p(2)}{p(3)}\)

    d) \((p(0) - p(1) + p(4))^2\)

    Ver Desarrollo

    Evaluamos recordando que el valor absoluto vuelve positiva cualquier cantidad en su interior: * \(p(0) = |0 - 5| - 0 = |-5| = 5\)

    • \(p(1) = |2 - 5| - 3 = |-3| - 3 = 3 - 3 = 0\)

    • \(p(2) = |4 - 5| - 6 = |-1| - 6 = 1 - 6 = -5\)

    • \(p(3) = |6 - 5| - 9 = |1| - 9 = 1 - 9 = -8\)

    • \(p(4) = |8 - 5| - 12 = |3| - 12 = 3 - 12 = -9\)

    • \(p(-1) = |-2 - 5| - 3(-1) = |-7| + 3 = 7 + 3 = 10\)

    Resolvemos: a) $\(p(1) + 3p(3) - p(0) = 0 + 3(-8) - 5 = -24 - 5 = -29\)$

    b) $\(-p(4) + (p(2))^2 = -(-9) + (-5)^2 = 9 + 25 = 34\)$

    c) $\(\dfrac{p(-1) - p(2)}{p(3)} = \dfrac{10 - (-5)}{-8} = -\dfrac{15}{8}\)$

    d) $\((p(0) - p(1) + p(4))^2 = (5 - 0 - 9)^2 = (-4)^2 = 16\)$

    Problema 5: Considere la función racional \(r:\mathbb{R}\to \mathbb{R}\) dada por:

    \[r(x) = \frac{x^3 - 8}{x^2 + 4}\]

    Calcule:

    a) \(r(2) + r(0) - 2r(-2)\)

    b) \(-r(1) + (r(-1))^2\)

    c) \(\dfrac{r(2) - r(-2)}{4}\)

    d) \((r(0) - r(1) + r(2))^2\)

    Ver Desarrollo

    Evaluamos los puntos requeridos: * \(r(0) = \frac{0 - 8}{0 + 4} = -2\)

    • \(r(1) = \frac{1 - 8}{1 + 4} = -\frac{7}{5}\)

    • \(r(-1) = \frac{-1 - 8}{1 + 4} = -\frac{9}{5}\)

    • \(r(2) = \frac{8 - 8}{4 + 4} = 0\)

    • \(r(-2) = \frac{-8 - 8}{4 + 4} = \frac{-16}{8} = -2\)

    Resolvemos: a) $\(r(2) + r(0) - 2r(-2) = 0 - 2 - 2(-2) = -2 + 4 = 2\)$

    b) $\(-r(1) + (r(-1))^2 = -\left(-\frac{7}{5}\right) + \left(-\frac{9}{5}\right)^2 = \frac{7}{5} + \frac{81}{25} = \frac{35 + 81}{25} = \frac{116}{25}\)$

    c) $\(\dfrac{r(2) - r(-2)}{4} = \dfrac{0 - (-2)}{4} = \dfrac{2}{4} = \frac{1}{2}\)$

    d) $\((r(0) - r(1) + r(2))^2 = \left(-2 - \left(-\frac{7}{5}\right) + 0\right)^2 = \left(-2 + \frac{7}{5}\right)^2 = \left(-\frac{3}{5}\right)^2 = \frac{9}{25}\)$

    Problema 6: Considere la función \(t:\mathbb{R}-\{-2, 2\}\to \mathbb{R}\) dada por:

    \[t(x) = \frac{x^2 - x - 2}{x^2 - 4}\]

    Calcule:

    a) \(t(3) + 4t(0) - t(1)\)

    b) \(-t(-1) + (t(-3))^2\)

    c) \(\dfrac{t(4) - t(0)}{t(1)}\)

    d) \((t(3) - t(-1) + t(0))^2\)

    Ver Desarrollo

    Notemos que podemos simplificar la función factorizando: $\(t(x) = \frac{(x - 2)(x + 1)}{(x - 2)(x + 2)} = \frac{x + 1}{x + 2} \quad \text{(para } x \neq 2, x \neq -2 \text{)}\)$

    Evaluamos usando la forma simplificada: * \(t(0) = \frac{0 + 1}{0 + 2} = \frac{1}{2}\)

    • \(t(1) = \frac{1 + 1}{1 + 2} = \frac{2}{3}\)

    • \(t(-1) = \frac{-1 + 1}{-1 + 2} = 0\)

    • \(t(3) = \frac{3 + 1}{3 + 2} = \frac{4}{5}\)

    • \(t(-3) = \frac{-3 + 1}{-3 + 2} = \frac{-2}{-1} = 2\)

    • \(t(4) = \frac{4 + 1}{4 + 2} = \frac{5}{6}\)

    Resolvemos: a) $\(t(3) + 4t(0) - t(1) = \frac{4}{5} + 4\left(\frac{1}{2}\right) - \frac{2}{3} = \frac{4}{5} + 2 - \frac{2}{3} = \frac{12 + 30 - 10}{15} = \frac{32}{15}\)$

    b) $\(-t(-1) + (t(-3))^2 = -0 + (2)^2 = 4\)$

    c) $\(\dfrac{t(4) - t(0)}{t(1)} = \dfrac{\frac{5}{6} - \frac{1}{2}}{\frac{2}{3}} = \dfrac{\frac{2}{6}}{\frac{2}{3}} = \dfrac{1/3}{2/3} = \frac{1}{2}\)$

    d) $\((t(3) - t(-1) + t(0))^2 = \left(\frac{4}{5} - 0 + \frac{1}{2}\right)^2 = \left(\frac{8 + 5}{10}\right)^2 = \left(\frac{13}{10}\right)^2 = \frac{169}{100}\)$

    Problema 7: Considere las funciones \(f(x) = 2x - 5\) y \(g(x) = x^2 - 3x + 2\).

    Determine las siguientes expresiones:

    a) \(g(-m)\)

    b) \(f(n-3)\)

    c) \(f(2m+1)g(1-m)\)

    d) \(\dfrac{f(3n)}{2 - g(n+1)}\)

    Ver Desarrollo

    Evaluamos cada expresión por separado:

    • \(g(-m) = (-m)^2 - 3(-m) + 2 = m^2 + 3m + 2\)

    • \(f(n-3) = 2(n-3) - 5 = 2n - 6 - 5 = 2n - 11\)

    • \(f(2m+1) = 2(2m+1) - 5 = 4m + 2 - 5 = 4m - 3\)

    • \(g(1-m) = (1-m)^2 - 3(1-m) + 2 = 1 - 2m + m^2 - 3 + 3m + 2 = m^2 + m\)

    • \(f(3n) = 2(3n) - 5 = 6n - 5\)

    • \(g(n+1) = (n+1)^2 - 3(n+1) + 2 = (n^2 + 2n + 1) - 3n - 3 + 2 = n^2 - n\)

    Resolvemos: a) $\(g(-m) = m^2 + 3m + 2\)$

    b) $\(f(n-3) = 2n - 11\)$

    c) $\(f(2m+1)g(1-m) = (4m - 3)(m^2 + m) = 4m^3 + 4m^2 - 3m^2 - 3m = 4m^3 + m^2 - 3m\)$

    d) $\(\dfrac{f(3n)}{2 - g(n+1)} = \dfrac{6n - 5}{2 - (n^2 - n)} = \dfrac{6n - 5}{-n^2 + n + 2}\)$

    Problema 8: Considere las funciones \(f(x) = -4x + 1\) y \(g(x) = -2x^2 + x - 3\).

    Determine las siguientes expresiones:

    a) \(g(-p)\)

    b) \(f(q+4)\)

    c) \(f(2p-1)g(3-p)\)

    d) \(\dfrac{f(-2q)}{g(2-q) - 1}\)

    Ver Desarrollo

    Evaluamos cada expresión por separado:

    • \(g(-p) = -2(-p)^2 + (-p) - 3 = -2p^2 - p - 3\)

    • \(f(q+4) = -4(q+4) + 1 = -4q - 16 + 1 = -4q - 15\)

    • \(f(2p-1) = -4(2p-1) + 1 = -8p + 4 + 1 = -8p + 5\)

    • \(g(3-p) = -2(3-p)^2 + (3-p) - 3 = -2(9 - 6p + p^2) + 3 - p - 3 = -18 + 12p - 2p^2 - p = -2p^2 + 11p - 18\)

    • \(f(-2q) = -4(-2q) + 1 = 8q + 1\)

    • \(g(2-q) = -2(2-q)^2 + (2-q) - 3 = -2(4 - 4q + q^2) + 2 - q - 3 = -8 + 8q - 2q^2 - 1 - q = -2q^2 + 7q - 9\)

    Resolvemos: a) $\(g(-p) = -2p^2 - p - 3\)$

    b) $\(f(q+4) = -4q - 15\)$

    c) $\(f(2p-1)g(3-p) = (-8p + 5)(-2p^2 + 11p - 18) = 16p^3 - 88p^2 + 144p - 10p^2 + 55p - 90 = 16p^3 - 98p^2 + 199p - 90\)$

    d) $\(\dfrac{f(-2q)}{g(2-q) - 1} = \dfrac{8q + 1}{(-2q^2 + 7q - 9) - 1} = \dfrac{8q + 1}{-2q^2 + 7q - 10}\)$

    Problema 9: Considere las funciones \(f(x) = 5x + 2\) y \(g(x) = 3x^2 - 2x + 4\).

    Determine las siguientes expresiones:

    a) \(g(-u)\)

    b) \(f(v-1)\)

    c) \(f(1-2u)g(u+2)\)

    d) \(\dfrac{f(3v)}{3 + g(1-2v)}\)

    Ver Desarrollo

    Evaluamos cada expresión por separado:

    • \(g(-u) = 3(-u)^2 - 2(-u) + 4 = 3u^2 + 2u + 4\)

    • \(f(v-1) = 5(v-1) + 2 = 5v - 5 + 2 = 5v - 3\)

    • \(f(1-2u) = 5(1-2u) + 2 = 5 - 10u + 2 = 7 - 10u\)

    • \(g(u+2) = 3(u+2)^2 - 2(u+2) + 4 = 3(u^2 + 4u + 4) - 2u - 4 + 4 = 3u^2 + 12u + 12 - 2u = 3u^2 + 10u + 12\)

    • \(f(3v) = 5(3v) + 2 = 15v + 2\)

    • \(g(1-2v) = 3(1-2v)^2 - 2(1-2v) + 4 = 3(1 - 4v + 4v^2) - 2 + 4v + 4 = 3 - 12v + 12v^2 + 2 + 4v = 12v^2 - 8v + 5\)

    Resolvemos: a) $\(g(-u) = 3u^2 + 2u + 4\)$

    b) $\(f(v-1) = 5v - 3\)$

    c) $\(f(1-2u)g(u+2) = (7 - 10u)(3u^2 + 10u + 12) = 21u^2 + 70u + 84 - 30u^3 - 100u^2 - 120u = -30u^3 - 79u^2 - 50u + 84\)$

    d) $\(\dfrac{f(3v)}{3 + g(1-2v)} = \dfrac{15v + 2}{3 + (12v^2 - 8v + 5)} = \dfrac{15v + 2}{12v^2 - 8v + 8}\)$

    Problema 10: Considere las funciones \(f(x) = -x - 6\) y \(g(x) = -x^2 - 5x + 2\).

    Determine las siguientes expresiones:

    a) \(g(-k)\)

    b) \(f(w+5)\)

    c) \(f(3k+2)g(2-3k)\)

    d) \(\dfrac{f(-w)}{4 - g(w-1)}\)

    Ver Desarrollo

    Evaluamos cada expresión por separado:

    • \(g(-k) = -(-k)^2 - 5(-k) + 2 = -k^2 + 5k + 2\)

    • \(f(w+5) = -(w+5) - 6 = -w - 5 - 6 = -w - 11\)

    • \(f(3k+2) = -(3k+2) - 6 = -3k - 2 - 6 = -3k - 8\)

    • \(g(2-3k) = -(2-3k)^2 - 5(2-3k) + 2 = -(4 - 12k + 9k^2) - 10 + 15k + 2 = -4 + 12k - 9k^2 - 8 + 15k = -9k^2 + 27k - 12\)

    • \(f(-w) = -(-w) - 6 = w - 6\)

    • \(g(w-1) = -(w-1)^2 - 5(w-1) + 2 = -(w^2 - 2w + 1) - 5w + 5 + 2 = -w^2 + 2w - 1 - 5w + 7 = -w^2 - 3w + 6\)

    Resolvemos: a) $\(g(-k) = -k^2 + 5k + 2\)$

    b) $\(f(w+5) = -w - 11\)$

    c) $\(f(3k+2)g(2-3k) = (-3k - 8)(-9k^2 + 27k - 12) = 27k^3 - 81k^2 + 36k + 72k^2 - 216k + 96 = 27k^3 - 9k^2 - 180k + 96\)$

    d) $\(\dfrac{f(-w)}{4 - g(w-1)} = \dfrac{w - 6}{4 - (-w^2 - 3w + 6)} = \dfrac{w - 6}{4 + w^2 + 3w - 6} = \dfrac{w - 6}{w^2 + 3w - 2}\)$

    Problema 11: Considere las funciones \(f(x) = 3x - 7\) y \(g(x) = 2x^2 + 6x - 1\).

    Determine las siguientes expresiones:

    a) \(g(-y)\)

    b) \(f(z-4)\)

    c) \(f(2y+3)g(1-4y)\)

    d) \(\dfrac{f(4z)}{2 + g(2-z)}\)

    Ver Desarrollo

    Evaluamos cada expresión por separado:

    • \(g(-y) = 2(-y)^2 + 6(-y) - 1 = 2y^2 - 6y - 1\)

    • \(f(z-4) = 3(z-4) - 7 = 3z - 12 - 7 = 3z - 19\)

    • \(f(2y+3) = 3(2y+3) - 7 = 6y + 9 - 7 = 6y + 2\)

    • \(g(1-4y) = 2(1-4y)^2 + 6(1-4y) - 1 = 2(1 - 8y + 16y^2) + 6 - 24y - 1 = 2 - 16y + 32y^2 + 5 - 24y = 32y^2 - 40y + 7\)

    • \(f(4z) = 3(4z) - 7 = 12z - 7\)

    • \(g(2-z) = 2(2-z)^2 + 6(2-z) - 1 = 2(4 - 4z + z^2) + 12 - 6z - 1 = 8 - 8z + 2z^2 + 11 - 6z = 2z^2 - 14z + 19\)

    Resolvemos: a) $\(g(-y) = 2y^2 - 6y - 1\)$

    b) $\(f(z-4) = 3z - 19\)$

    c) $\(f(2y+3)g(1-4y) = (6y + 2)(32y^2 - 40y + 7) = 192y^3 - 240y^2 + 42y + 64y^2 - 80y + 14 = 192y^3 - 176y^2 - 38y + 14\)$

    d) $\(\dfrac{f(4z)}{2 + g(2-z)} = \dfrac{12z - 7}{2 + (2z^2 - 14z + 19)} = \dfrac{12z - 7}{2z^2 - 14z + 21}\)$

    Problema 12: Considere la función exponencial \(s:\mathbb{R}\to \mathbb{R}\) dada por:

    \[s(x) = 2^{x+1} - 3x\]

    Calcule:

    a) \(s(0) + 2s(1) - s(2)\)

    b) \(-s(3) + (s(-1))^2\)

    c) \(\dfrac{s(2) - s(0)}{s(1)}\)

    d) \((s(1) - s(0) + s(-2))^2\)

    Ver Desarrollo

    Evaluamos:

    • \(s(0) = 2^{0+1} - 3(0) = 2^1 = 2\)

    • \(s(1) = 2^{1+1} - 3(1) = 4 - 3 = 1\)

    • \(s(2) = 2^{2+1} - 3(2) = 8 - 6 = 2\)

    • \(s(3) = 2^{3+1} - 3(3) = 16 - 9 = 7\)

    • \(s(-1) = 2^{-1+1} - 3(-1) = 2^0 + 3 = 1 + 3 = 4\)

    • \(s(-2) = 2^{-2+1} - 3(-2) = 2^{-1} + 6 = \frac{1}{2} + 6 = \frac{13}{2}\)

    Resolvemos: a) $\(s(0) + 2s(1) - s(2) = 2 + 2(1) - 2 = 2\)$

    b) $\(-s(3) + (s(-1))^2 = -7 + (4)^2 = -7 + 16 = 9\)$

    c) $\(\dfrac{s(2) - s(0)}{s(1)} = \dfrac{2 - 2}{1} = 0\)$

    d) $\((s(1) - s(0) + s(-2))^2 = \left(1 - 2 + \frac{13}{2}\right)^2 = \left(-1 + \frac{13}{2}\right)^2 = \left(\frac{11}{2}\right)^2 = \frac{121}{4}\)$
