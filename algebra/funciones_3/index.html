    Problema 1: Considere la función polinomial \(f:\mathbb{R}\to \mathbb{R}\) dada por:

    \[f(x) = 2x^2 - 5x + 3\]

    Calcule: a) \(f(1) + f(0) - 2f(-1)\)

    b) \(-f(2) + (f(3))^2\)

    c) \(\dfrac{f(4) - f(-2)}{3}\)

    d) \((f(2) - f(0) + f(1))^2\)

    Ver Desarrollo

    Primero, evaluamos la función en los valores necesarios: * \(f(0) = 2(0)^2 - 5(0) + 3 = 3\) * \(f(1) = 2(1)^2 - 5(1) + 3 = 2 - 5 + 3 = 0\) * \(f(-1) = 2(-1)^2 - 5(-1) + 3 = 2 + 5 + 3 = 10\) * \(f(2) = 2(2)^2 - 5(2) + 3 = 8 - 10 + 3 = 1\) * \(f(3) = 2(3)^2 - 5(3) + 3 = 18 - 15 + 3 = 6\) * \(f(4) = 2(4)^2 - 5(4) + 3 = 32 - 20 + 3 = 15\) * \(f(-2) = 2(-2)^2 - 5(-2) + 3 = 8 + 10 + 3 = 21\)

    Ahora, resolvemos cada expresión: a) \(f(1) + f(0) - 2f(-1) = 0 + 3 - 2(10) = 3 - 20 = -17\) b) \(-f(2) + (f(3))^2 = -1 + (6)^2 = -1 + 36 = 35\) c) \(\dfrac{f(4) - f(-2)}{3} = \dfrac{15 - 21}{3} = \dfrac{-6}{3} = -2\) d) \((f(2) - f(0) + f(1))^2 = (1 - 3 + 0)^2 = (-2)^2 = 4\)

    Problema 2: Considere la función racional \(g:\mathbb{R}-\{-2\}\to \mathbb{R}\) dada por:

    \[g(x) = \frac{3x - 1}{x + 2}\]

    Calcule: a) \(g(1) + 2g(0) - g(-1)\)

    b) \(-g(2) + (g(-3))^2\)

    c) \(\dfrac{g(3) - g(0)}{g(-1)}\)

    d) \((g(1) - g(-3) + g(0))^2\)

    Ver Desarrollo

    Evaluamos la función en los puntos requeridos: * \(g(0) = \frac{0 - 1}{0 + 2} = -\frac{1}{2}\) * \(g(1) = \frac{3(1) - 1}{1 + 2} = \frac{2}{3}\) * \(g(-1) = \frac{3(-1) - 1}{-1 + 2} = \frac{-4}{1} = -4\) * \(g(2) = \frac{3(2) - 1}{2 + 2} = \frac{5}{4}\) * \(g(-3) = \frac{3(-3) - 1}{-3 + 2} = \frac{-10}{-1} = 10\) * \(g(3) = \frac{3(3) - 1}{3 + 2} = \frac{8}{5}\)

    Resolvemos: a) \(g(1) + 2g(0) - g(-1) = \frac{2}{3} + 2\left(-\frac{1}{2}\right) - (-4) = \frac{2}{3} - 1 + 4 = 3 + \frac{2}{3} = \frac{11}{3}\) b) \(-g(2) + (g(-3))^2 = -\frac{5}{4} + (10)^2 = -\frac{5}{4} + 100 = \frac{395}{4}\) c) \(\dfrac{g(3) - g(0)}{g(-1)} = \dfrac{\frac{8}{5} - \left(-\frac{1}{2}\right)}{-4} = \dfrac{\frac{16 + 5}{10}}{-4} = \dfrac{21/10}{-4} = -\frac{21}{40}\) d) \((g(1) - g(-3) + g(0))^2 = \left(\frac{2}{3} - 10 - \frac{1}{2}\right)^2 = \left(\frac{4 - 60 - 3}{6}\right)^2 = \left(-\frac{59}{6}\right)^2 = \frac{3481}{36}\)

    Problema 3: Considere la función definida por tramos \(h:\mathbb{R}\to \mathbb{R}\) dada por:

    \[h(x) = \begin{cases} 3x + 1 & \text{si } x < 1 \\ x^2 - 2 & \text{si } x \ge 1 \end{cases}\]

    Calcule: a) \(h(0) + h(2) - 2h(1)\)

    b) \(-h(-2) + (h(3))^2\)

    c) \(\dfrac{h(4) - h(-1)}{2}\)

    d) \((h(2) - h(0) + h(-3))^2\)

    Ver Desarrollo

    Evaluamos prestando atención al tramo correspondiente: * \(x=0 < 1 \implies h(0) = 3(0) + 1 = 1\) * \(x=1 \ge 1 \implies h(1) = 1^2 - 2 = -1\) * \(x=2 \ge 1 \implies h(2) = 2^2 - 2 = 2\) * \(x=-1 < 1 \implies h(-1) = 3(-1) + 1 = -2\) * \(x=-2 < 1 \implies h(-2) = 3(-2) + 1 = -5\) * \(x=-3 < 1 \implies h(-3) = 3(-3) + 1 = -8\) * \(x=3 \ge 1 \implies h(3) = 3^2 - 2 = 7\) * \(x=4 \ge 1 \implies h(4) = 4^2 - 2 = 14\)

    Resolvemos: a) \(h(0) + h(2) - 2h(1) = 1 + 2 - 2(-1) = 3 + 2 = 5\) b) \(-h(-2) + (h(3))^2 = -(-5) + (7)^2 = 5 + 49 = 54\) c) \(\dfrac{h(4) - h(-1)}{2} = \dfrac{14 - (-2)}{2} = \dfrac{16}{2} = 8\) d) \((h(2) - h(0) + h(-3))^2 = (2 - 1 - 8)^2 = (-7)^2 = 49\)

    Problema 4: Considere la función con valor absoluto \(p:\mathbb{R}\to \mathbb{R}\) dada por:

    \[p(x) = |2x - 5| - 3x\]

    Calcule: a) \(p(1) + 3p(3) - p(0)\)

    b) \(-p(4) + (p(2))^2\)

    c) \(\dfrac{p(-1) - p(2)}{p(3)}\)

    d) \((p(0) - p(1) + p(4))^2\)

    Ver Desarrollo

    Evaluamos recordando que el valor absoluto vuelve positiva cualquier cantidad en su interior: * \(p(0) = |0 - 5| - 0 = |-5| = 5\) * \(p(1) = |2 - 5| - 3 = |-3| - 3 = 3 - 3 = 0\) * \(p(2) = |4 - 5| - 6 = |-1| - 6 = 1 - 6 = -5\) * \(p(3) = |6 - 5| - 9 = |1| - 9 = 1 - 9 = -8\) * \(p(4) = |8 - 5| - 12 = |3| - 12 = 3 - 12 = -9\) * \(p(-1) = |-2 - 5| - 3(-1) = |-7| + 3 = 7 + 3 = 10\)

    Resolvemos: a) \(p(1) + 3p(3) - p(0) = 0 + 3(-8) - 5 = -24 - 5 = -29\) b) \(-p(4) + (p(2))^2 = -(-9) + (-5)^2 = 9 + 25 = 34\) c) \(\dfrac{p(-1) - p(2)}{p(3)} = \dfrac{10 - (-5)}{-8} = -\dfrac{15}{8}\) d) \((p(0) - p(1) + p(4))^2 = (5 - 0 - 9)^2 = (-4)^2 = 16\)

    Problema 5: Considere la función racional \(r:\mathbb{R}\to \mathbb{R}\) dada por:

    \[r(x) = \frac{x^3 - 8}{x^2 + 4}\]

    Calcule: a) \(r(2) + r(0) - 2r(-2)\)

    b) \(-r(1) + (r(-1))^2\)

    c) \(\dfrac{r(2) - r(-2)}{4}\)

    d) \((r(0) - r(1) + r(2))^2\)

    Ver Desarrollo

    Evaluamos los puntos requeridos: * \(r(0) = \frac{0 - 8}{0 + 4} = -2\) * \(r(1) = \frac{1 - 8}{1 + 4} = -\frac{7}{5}\) * \(r(-1) = \frac{-1 - 8}{1 + 4} = -\frac{9}{5}\) * \(r(2) = \frac{8 - 8}{4 + 4} = 0\) * \(r(-2) = \frac{-8 - 8}{4 + 4} = \frac{-16}{8} = -2\)

    Resolvemos: a) \(r(2) + r(0) - 2r(-2) = 0 - 2 - 2(-2) = -2 + 4 = 2\) b) \(-r(1) + (r(-1))^2 = -\left(-\frac{7}{5}\right) + \left(-\frac{9}{5}\right)^2 = \frac{7}{5} + \frac{81}{25} = \frac{35 + 81}{25} = \frac{116}{25}\) c) \(\dfrac{r(2) - r(-2)}{4} = \dfrac{0 - (-2)}{4} = \dfrac{2}{4} = \frac{1}{2}\) d) \((r(0) - r(1) + r(2))^2 = \left(-2 - \left(-\frac{7}{5}\right) + 0\right)^2 = \left(-2 + \frac{7}{5}\right)^2 = \left(-\frac{3}{5}\right)^2 = \frac{9}{25}\)

    Problema 6: Considere la función \(t:\mathbb{R}-\{-2, 2\}\to \mathbb{R}\) dada por:

    \[t(x) = \frac{x^2 - x - 2}{x^2 - 4}\]

    Calcule: a) \(t(3) + 4t(0) - t(1)\)

    b) \(-t(-1) + (t(-3))^2\)

    c) \(\dfrac{t(4) - t(0)}{t(1)}\)

    d) \((t(3) - t(-1) + t(0))^2\)

    Ver Desarrollo

    Notemos que podemos simplificar la función factorizando: $\(t(x) = \frac{(x - 2)(x + 1)}{(x - 2)(x + 2)} = \frac{x + 1}{x + 2} \quad \text{(para } x \neq 2, x \neq -2 \text{)}\)$

    Evaluamos usando la forma simplificada: * \(t(0) = \frac{0 + 1}{0 + 2} = \frac{1}{2}\) * \(t(1) = \frac{1 + 1}{1 + 2} = \frac{2}{3}\) * \(t(-1) = \frac{-1 + 1}{-1 + 2} = 0\) * \(t(3) = \frac{3 + 1}{3 + 2} = \frac{4}{5}\) * \(t(-3) = \frac{-3 + 1}{-3 + 2} = \frac{-2}{-1} = 2\) * \(t(4) = \frac{4 + 1}{4 + 2} = \frac{5}{6}\)

    Resolvemos: a) \(t(3) + 4t(0) - t(1) = \frac{4}{5} + 4\left(\frac{1}{2}\right) - \frac{2}{3} = \frac{4}{5} + 2 - \frac{2}{3} = \frac{12 + 30 - 10}{15} = \frac{32}{15}\) b) \(-t(-1) + (t(-3))^2 = -0 + (2)^2 = 4\) c) \(\dfrac{t(4) - t(0)}{t(1)} = \dfrac{\frac{5}{6} - \frac{1}{2}}{\frac{2}{3}} = \dfrac{\frac{2}{6}}{\frac{2}{3}} = \dfrac{1/3}{2/3} = \frac{1}{2}\) d) \((t(3) - t(-1) + t(0))^2 = \left(\frac{4}{5} - 0 + \frac{1}{2}\right)^2 = \left(\frac{8 + 5}{10}\right)^2 = \left(\frac{13}{10}\right)^2 = \frac{169}{100}\)

    Problema 7: Considere la función \(q:[-3, \infty)-\{1\}\to \mathbb{R}\) dada por:

    \[q(x) = \frac{\sqrt{x + 3}}{x - 1}\]

    Calcule: a) \(q(6) + 2q(13) - q(-2)\)

    b) \(-q(22) + (q(-3))^2\)

    c) \(\dfrac{q(6) - q(-2)}{q(13)}\)

    d) \((q(6) - q(22) + q(-2))^2\)

    Ver Desarrollo

    Evaluamos: * \(q(6) = \frac{\sqrt{6 + 3}}{6 - 1} = \frac{\sqrt{9}}{5} = \frac{3}{5}\) * \(q(13) = \frac{\sqrt{13 + 3}}{13 - 1} = \frac{\sqrt{16}}{12} = \frac{4}{12} = \frac{1}{3}\) * \(q(-2) = \frac{\sqrt{-2 + 3}}{-2 - 1} = \frac{\sqrt{1}}{-3} = -\frac{1}{3}\) * \(q(22) = \frac{\sqrt{22 + 3}}{22 - 1} = \frac{\sqrt{25}}{21} = \frac{5}{21}\) * \(q(-3) = \frac{\sqrt{-3 + 3}}{-3 - 1} = \frac{0}{-4} = 0\)

    Resolvemos: a) \(q(6) + 2q(13) - q(-2) = \frac{3}{5} + 2\left(\frac{1}{3}\right) - \left(-\frac{1}{3}\right) = \frac{3}{5} + \frac{2}{3} + \frac{1}{3} = \frac{3}{5} + 1 = \frac{8}{5}\) b) \(-q(22) + (q(-3))^2 = -\frac{5}{21} + (0)^2 = -\frac{5}{21}\) c) \(\dfrac{q(6) - q(-2)}{q(13)} = \dfrac{\frac{3}{5} - \left(-\frac{1}{3}\right)}{\frac{1}{3}} = \dfrac{\frac{9+5}{15}}{1/3} = \dfrac{14/15}{1/3} = \frac{14}{5}\) d) \((q(6) - q(22) + q(-2))^2 = \left(\frac{3}{5} - \frac{5}{21} - \frac{1}{3}\right)^2 = \left(\frac{63 - 25 - 35}{105}\right)^2 = \left(\frac{3}{105}\right)^2 = \left(\frac{1}{35}\right)^2 = \frac{1}{1225}\)

    Problema 8: Considere la función exponencial \(s:\mathbb{R}\to \mathbb{R}\) dada por:

    \[s(x) = 2^{x+1} - 3x\]

    Calcule: a) \(s(0) + 2s(1) - s(2)\)

    b) \(-s(3) + (s(-1))^2\)

    c) \(\dfrac{s(2) - s(0)}{s(1)}\)

    d) \((s(1) - s(0) + s(-2))^2\)

    Ver Desarrollo

    Evaluamos: * \(s(0) = 2^{0+1} - 3(0) = 2^1 = 2\) * \(s(1) = 2^{1+1} - 3(1) = 4 - 3 = 1\) * \(s(2) = 2^{2+1} - 3(2) = 8 - 6 = 2\) * \(s(3) = 2^{3+1} - 3(3) = 16 - 9 = 7\) * \(s(-1) = 2^{-1+1} - 3(-1) = 2^0 + 3 = 1 + 3 = 4\) * \(s(-2) = 2^{-2+1} - 3(-2) = 2^{-1} + 6 = \frac{1}{2} + 6 = \frac{13}{2}\)

    Resolvemos: a) \(s(0) + 2s(1) - s(2) = 2 + 2(1) - 2 = 2\) b) \(-s(3) + (s(-1))^2 = -7 + (4)^2 = -7 + 16 = 9\) c) \(\dfrac{s(2) - s(0)}{s(1)} = \dfrac{2 - 2}{1} = 0\) d) \((s(1) - s(0) + s(-2))^2 = \left(1 - 2 + \frac{13}{2}\right)^2 = \left(-1 + \frac{13}{2}\right)^2 = \left(\frac{11}{2}\right)^2 = \frac{121}{4}\)
