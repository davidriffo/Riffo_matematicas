    Reglas de derivación

    Colección de problemas para ejercitar las reglas de derivación: potencias, sumas, producto, cociente y regla de la cadena. El rasgo distintivo de esta sección es que la elección de la estrategia importa tanto como el cálculo: muchas derivaciones se vuelven triviales si se simplifica antes, y la regla de la cadena exige identificar con cuidado qué función está "dentro" de cuál.

    Reglas fundamentales

    Sean \(f\) y \(g\) funciones derivables, y \(a\), \(b\) constantes.

    Regla Fórmula
    Potencias \((x^\alpha)' = \alpha\,x^{\alpha-1}\)
    Exponencial y logaritmo \((e^x)' = e^x, \quad (a^x)' = \ln(a)\,a^x, \quad (\ln x)' = \dfrac1x, \quad (\log_a x)' = \dfrac{1}{x\ln a}\)
    Suma y constantes \((af \pm bg)' = af' \pm bg'\)
    Producto \((fg)' = f'g + fg'\)
    Cociente \(\left(\dfrac fg\right)' = \dfrac{f'g - fg'}{g^2}\)
    Cadena \(\big(f(g(x))\big)' = f'\big(g(x)\big)\cdot g'(x)\)

    La cadena en una frase. Se deriva la función exterior evaluada en la interior sin tocarla, y se multiplica por la derivada de la interior. Casos que se usan constantemente:

    \[\big(u^n\big)' = n\,u^{n-1}u', \qquad \big(e^{u}\big)' = u'\,e^{u}, \qquad \big(\ln u\big)' = \frac{u'}{u}, \qquad \big(\sqrt{u}\big)' = \frac{u'}{2\sqrt{u}}.\]

    Las tres trampas de esta sección

    1. Olvidar la derivada de la función interior. Es el error más frecuente con la cadena: \(\big((x^2+1)^4\big)'\) no es \(4(x^2+1)^3\); falta multiplicar por \(2x\).
    2. Derivar un producto o un cociente "término a término". Es falso que \((fg)' = f'g'\) y que \(\left(\frac fg\right)' = \frac{f'}{g'}\). Además, en el cociente el orden del numerador importa: es \(f'g - fg'\), y no al revés.
    3. No simplificar antes de derivar. Reescribir raíces como potencias, dividir término a término o usar propiedades de logaritmos evita reglas pesadas. Y al simplificar hay que recordar el dominio original: \(\frac{x^2-4}{x-2}\) y \(x+2\) no son la misma función en \(x=2\).

    Potencias, sumas y constantes

    Problema 1

    Derive cada función, reescribiendo primero cada término como potencia de \(x\) cuando sea necesario.

    1. \(f(x) = 7x^3 - 4x^2 + x - 9\)
    2. \(g(x) = \dfrac{5}{x^4}\)
    3. \(h(x) = 3\sqrt[3]{x}\)
    4. \(k(x) = x^2\sqrt{x}\)
    5. \(m(x) = \dfrac{4}{3x^2}\)
    Ver desarrollo

    Idea. Ninguna de estas funciones necesita producto ni cociente: basta reescribir cada una como suma de potencias y aplicar \((x^\alpha)' = \alpha x^{\alpha-1}\).

    Reescritura Derivada
    1 \(7x^3 - 4x^2 + x - 9\) \(21x^2 - 8x + 1\)
    2 \(5x^{-4}\) \(-20x^{-5} = -\dfrac{20}{x^5}\)
    3 \(3x^{1/3}\) \(x^{-2/3} = \dfrac{1}{\sqrt[3]{x^2}}\)
    4 \(x^2\cdot x^{1/2} = x^{5/2}\) \(\dfrac52 x^{3/2} = \dfrac52\,x\sqrt{x}\)
    5 \(\dfrac43\,x^{-2}\) \(-\dfrac83\,x^{-3} = -\dfrac{8}{3x^3}\)

    Solución

    \[f' = 21x^2 - 8x + 1, \quad g' = -\frac{20}{x^5}, \quad h' = \frac{1}{\sqrt[3]{x^2}}, \quad k' = \frac52\,x\sqrt{x}, \quad m' = -\frac{8}{3x^3}.\]

    En el apartado 4

    Es tentador usar la regla del producto con \(x^2\) y \(\sqrt{x}\). Funciona, pero al sumar exponentes (\(2 + \tfrac12 = \tfrac52\)) la derivada sale en una sola línea.

    Problema 2

    Derive cada función sin usar las reglas del producto ni del cociente: simplifique primero. Indique también el dominio de cada derivada.

    1. \(f(x) = \dfrac{x^2 - 4}{x - 2}\)
    2. \(g(x) = (x+1)(x^2 - x + 1)\)
    3. \(h(x) = \dfrac{x^2 + 3x}{\sqrt{x}}\)
    4. \(k(x) = \left(\sqrt{x} + 1\right)^2\)
    Ver desarrollo

    1. Para \(x \ne 2\), factorizamos: \(\dfrac{x^2-4}{x-2} = \dfrac{(x-2)(x+2)}{x-2} = x + 2\), luego \(f'(x) = 1\).

    2. Expandiendo, \((x+1)(x^2 - x + 1) = x^3 + 1\), luego \(g'(x) = 3x^2\).

    3. Dividiendo término a término:

    \[h(x) = \frac{x^2}{x^{1/2}} + \frac{3x}{x^{1/2}} = x^{3/2} + 3x^{1/2} \implies h'(x) = \frac32 x^{1/2} + \frac32 x^{-1/2} = \frac32\left(\sqrt{x} + \frac{1}{\sqrt{x}}\right).\]

    4. Expandiendo el cuadrado, \(k(x) = x + 2\sqrt{x} + 1\), y entonces

    \[k'(x) = 1 + \frac{1}{\sqrt{x}}.\]

    Solución

    Derivada Dominio de la derivada
    1 \(f'(x) = 1\) \(x \ne 2\)
    2 \(g'(x) = 3x^2\) \(\mathbb{R}\)
    3 \(h'(x) = \tfrac32\left(\sqrt{x} + \tfrac{1}{\sqrt{x}}\right)\) \(x > 0\)
    4 \(k'(x) = 1 + \tfrac{1}{\sqrt{x}}\) \(x > 0\)

    Cuidado con el apartado 1

    \(f(x) = \frac{x^2-4}{x-2}\) no está definida en \(x=2\), aunque la expresión simplificada \(x+2\) sí lo esté. La derivada es \(1\) en todo punto excepto \(x=2\): la simplificación no puede "rellenar" el hueco del dominio.

    Problema 3

    Derive cada función, usando propiedades de exponentes y logaritmos cuando convenga.

    1. \(f(x) = 4e^x - 3\cdot 5^x\)
    2. \(g(x) = \ln(5x)\)
    3. \(h(x) = \log_2 x + e^{x-1}\)
    4. \(k(x) = \ln\sqrt{x}\)
    5. \(m(x) = 3^{x+1}\)
    6. \(n(x) = \pi^e + x^\pi\)
    Ver desarrollo

    Estrategia. Salvo en el apartado 1, conviene transformar la expresión antes de derivar, de modo que no aparezca ninguna composición.

    1. Aplicamos \((a^x)' = \ln(a)\,a^x\) a cada término: \(f'(x) = 4e^x - 3\ln 5\cdot 5^x\).
    2. Como \(\ln(5x) = \ln 5 + \ln x\) y \(\ln 5\) es una constante, \(g'(x) = \dfrac1x\).
    3. Escribimos \(e^{x-1} = e^{-1}e^x\), luego \(h'(x) = \dfrac{1}{x\ln 2} + e^{x-1}\).
    4. Como \(\ln\sqrt{x} = \tfrac12\ln x\), se tiene \(k'(x) = \dfrac{1}{2x}\).
    5. Como \(3^{x+1} = 3\cdot 3^x\), se tiene \(m'(x) = 3\ln 3\cdot 3^x = \ln 3\cdot 3^{x+1}\).
    6. \(\pi^e\) es una constante (su derivada es \(0\)) y \(x^\pi\) es una potencia: \(n'(x) = \pi\,x^{\pi - 1}\).

    Solución

    \[f' = 4e^x - 3\ln 5\cdot 5^x, \quad g' = \frac1x, \quad h' = \frac{1}{x\ln 2} + e^{x-1}, \quad k' = \frac{1}{2x}, \quad m' = \ln 3\cdot 3^{x+1}, \quad n' = \pi\,x^{\pi-1}.\]

    Potencia o exponencial

    Hay que distinguir \(x^\pi\) (base variable, exponente constante: regla de potencias) de \(\pi^x\) (base constante, exponente variable: regla exponencial, con factor \(\ln\pi\)). Confundirlas es un error clásico.

    Problema 4

    Sea \(f(x) = x^3 - 6x^2 + 9x + 1\).

    1. Calcule \(f'(x)\) y factorícela.
    2. Encuentre los puntos de la gráfica donde la recta tangente es horizontal.
    3. Escriba la ecuación de la recta tangente en \(x = 0\).
    Ver desarrollo

    Parte 1.

    \[f'(x) = 3x^2 - 12x + 9 = 3\,(x^2 - 4x + 3) = 3(x-1)(x-3).\]

    Parte 2. La tangente es horizontal donde \(f'(x) = 0\), es decir en \(x = 1\) y \(x = 3\):

    \[f(1) = 1 - 6 + 9 + 1 = 5, \qquad f(3) = 27 - 54 + 27 + 1 = 1.\]

    Parte 3. En \(x = 0\): \(f(0) = 1\) y \(f'(0) = 9\), luego

    \[y = 1 + 9x.\]

    Solución

    \[f'(x) = 3(x-1)(x-3), \qquad \text{tangentes horizontales en } (1,5) \text{ y } (3,1), \qquad y = 9x + 1.\]

    Qué indican esos puntos

    \(f'\) es positiva en \(]-\infty,1[\), negativa en \(]1,3[\) y positiva en \(]3,+\infty[\). Entonces \((1,5)\) es un máximo local y \((3,1)\) un mínimo local: la gráfica sube, baja y vuelve a subir.

    Producto y cociente

    Problema 5

    Derive con la regla del producto y simplifique:

    1. \(f(x) = x^3\ln x\)
    2. \(g(x) = (x^2 - x)\,e^x\)
    3. \(h(x) = x^3\,2^x\)
    Ver desarrollo

    Receta. Se identifican los dos factores \(u\) y \(v\), se calculan \(u'\) y \(v'\) por separado, y se arma \(u'v + uv'\).

    1. Con \(u = x^3\) y \(v = \ln x\):

    \[f'(x) = 3x^2\ln x + x^3\cdot\frac1x = 3x^2\ln x + x^2 = x^2\,(3\ln x + 1).\]

    2. Con \(u = x^2 - x\) y \(v = e^x\):

    \[g'(x) = (2x - 1)e^x + (x^2 - x)e^x = (x^2 + x - 1)\,e^x.\]

    3. Con \(u = x^3\) y \(v = 2^x\):

    \[h'(x) = 3x^2\,2^x + x^3\ln 2\cdot 2^x = x^2\,2^x\,(x\ln 2 + 3).\]

    Solución

    \[f' = x^2(3\ln x + 1), \qquad g' = (x^2 + x - 1)\,e^x, \qquad h' = x^2\,2^x\,(x\ln 2 + 3).\]

    Factorizar siempre

    Dejar el resultado factorizado (\(e^x\) afuera, o \(x^2\,2^x\) afuera) no es un adorno: facilita ver dónde se anula la derivada, que es lo primero que se pregunta después.

    Problema 6

    Derive con la regla del cociente y simplifique:

    1. \(f(x) = \dfrac{x^2 - 1}{x^2 + 1}\)
    2. \(g(x) = \dfrac{x}{e^x}\)
    3. \(h(x) = \dfrac{\ln x}{x^2}\)
    4. \(k(x) = \dfrac{x^2 + 1}{x}\). Luego verifique el resultado dividiendo primero término a término.
    Ver desarrollo

    Receta. \(\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}\). El numerador conserva el orden: primero derivada del de arriba.

    1.

    \[f'(x) = \frac{2x(x^2+1) - (x^2-1)(2x)}{(x^2+1)^2} = \frac{2x\,[(x^2+1) - (x^2-1)]}{(x^2+1)^2} = \frac{4x}{(x^2+1)^2}.\]

    2.

    \[g'(x) = \frac{1\cdot e^x - x\,e^x}{(e^x)^2} = \frac{(1 - x)\,e^x}{e^{2x}} = \frac{1 - x}{e^x}.\]

    3.

    \[h'(x) = \frac{\frac1x\cdot x^2 - \ln x\cdot 2x}{x^4} = \frac{x - 2x\ln x}{x^4} = \frac{1 - 2\ln x}{x^3}.\]

    4. Por cociente:

    \[k'(x) = \frac{2x\cdot x - (x^2+1)\cdot 1}{x^2} = \frac{x^2 - 1}{x^2}.\]

    Por simplificación, \(k(x) = x + \dfrac1x \implies k'(x) = 1 - \dfrac{1}{x^2} = \dfrac{x^2-1}{x^2}\). Coinciden. \(\checkmark\)

    Solución

    \[f' = \frac{4x}{(x^2+1)^2}, \qquad g' = \frac{1-x}{e^x}, \qquad h' = \frac{1 - 2\ln x}{x^3}, \qquad k' = \frac{x^2-1}{x^2}.\]

    Antes de usar el cociente

    En el apartado 4 la regla del cociente era innecesaria: el denominador es un monomio y basta dividir. Pregúntese siempre si el denominador "divide" a cada término del numerador.

    Problema 7

    Sea \(f(x) = \dfrac{x}{x^2 + 1}\).

    1. Calcule \(f'(x)\) y factorice el numerador.
    2. Encuentre los puntos de la gráfica con tangente horizontal.
    3. Estudie el signo de \(f'\) y describa cómo se comporta \(f\).
    Ver desarrollo

    Parte 1. Por la regla del cociente:

    \[f'(x) = \frac{1\cdot(x^2+1) - x\cdot 2x}{(x^2+1)^2} = \frac{1 - x^2}{(x^2+1)^2} = \frac{(1-x)(1+x)}{(x^2+1)^2}.\]

    Parte 2. El denominador nunca se anula, así que \(f'(x) = 0\) solo si \(1 - x^2 = 0\), es decir \(x = \pm 1\):

    \[f(1) = \frac12, \qquad f(-1) = -\frac12.\]

    Parte 3. El denominador es siempre positivo, de modo que el signo lo decide \(1 - x^2\):

    Intervalo \(]-\infty,-1[\) \(]-1,1[\) \(]1,+\infty[\)
    \(f'(x)\) \(-\) \(\boldsymbol{+}\) \(-\)
    \(f\) decrece crece decrece

    Solución

    \[f'(x) = \frac{1-x^2}{(x^2+1)^2}, \qquad \text{tangentes horizontales en } \left(1,\tfrac12\right) \text{ y } \left(-1,-\tfrac12\right).\]

    \(f\) tiene un mínimo local en \(x=-1\) y un máximo local en \(x=1\).

    Problema 8

    Determine las constantes \(a\) y \(b\) para que la gráfica de

    \[f(x) = \frac{ax + b}{x + 1}\]

    pase por el punto \((0, 2)\) y tenga allí recta tangente de pendiente \(-1\).

    Ver desarrollo

    Derivada. Con la regla del cociente:

    \[f'(x) = \frac{a(x+1) - (ax+b)}{(x+1)^2} = \frac{a - b}{(x+1)^2}.\]

    Dos condiciones, dos incógnitas.

    1. Pasa por \((0,2)\): \(f(0) = b = 2\).
    2. Pendiente \(-1\) en \(x=0\): \(f'(0) = a - b = -1\).

    De la primera, \(b = 2\), y de la segunda, \(a = b - 1 = 1\).

    Solución

    \[a = 1, \qquad b = 2, \qquad f(x) = \frac{x+2}{x+1}.\]

    Verificación

    \(f(0) = 2\). \(\checkmark\) Con \(f'(x) = \dfrac{-1}{(x+1)^2}\) se tiene \(f'(0) = -1\). \(\checkmark\) Note que el numerador de \(f'\) es \(a-b\), una constante: si fuera \(a = b\) la función sería constante y \(f' \equiv 0\).

    Problema 9

    FÁRMACO. La concentración en sangre (en mg/L) de un medicamento, \(t\) horas después de ser administrado, es

    \[C(t) = \frac{5t}{t^2 + 4}, \qquad t \ge 0.\]
    1. Calcule \(C'(t)\) y simplifique.
    2. ¿En qué instante la concentración deja de crecer? ¿Cuál es entonces la concentración?
    3. Determine el signo de \(C'(t)\) antes y después de ese instante e interprételo.
    Ver desarrollo

    Parte 1. Regla del cociente:

    \[C'(t) = \frac{5(t^2+4) - 5t\cdot 2t}{(t^2+4)^2} = \frac{5\,(4 - t^2)}{(t^2+4)^2}.\]

    Parte 2. El denominador es positivo, así que \(C'(t) = 0\) exige \(4 - t^2 = 0\). Con \(t \ge 0\) se obtiene \(t = 2\):

    \[C(2) = \frac{10}{8} = \frac54 = 1{,}25 \text{ mg/L}.\]

    Parte 3.

    Intervalo \([0, 2[\) \(]2, +\infty[\)
    \(4 - t^2\) \(+\) \(-\)
    \(C'(t)\) \(\boldsymbol{+}\) \(-\)

    Solución

    \[C'(t) = \frac{5(4-t^2)}{(t^2+4)^2}.\]

    La concentración alcanza su valor máximo, \(1{,}25\) mg/L, a las 2 horas: antes de ese instante aumenta (el fármaco se absorbe) y después disminuye (se elimina).

    Comportamiento a largo plazo

    Para \(t\) grande, \(C(t) \approx \tfrac{5}{t} \to 0\), de modo que el fármaco termina por desaparecer. Un máximo seguido de decaimiento es la forma típica de una curva de concentración.

    Problema 10

    Sea \(f(x) = \dfrac{x^2}{x - 1}\).

    1. Derive \(f\) con la regla del cociente.
    2. Derive \(f\) por segunda vez escribiéndola primero como \(x + 1 + \dfrac{1}{x-1}\), y verifique que obtiene lo mismo.
    3. Encuentre los puntos con tangente horizontal y la recta tangente en \(x = 3\).
    Ver desarrollo

    Parte 1. Por el cociente:

    \[f'(x) = \frac{2x(x-1) - x^2\cdot 1}{(x-1)^2} = \frac{x^2 - 2x}{(x-1)^2} = \frac{x(x-2)}{(x-1)^2}.\]

    Parte 2. Para ver la reescritura, dividimos: \(\dfrac{x^2}{x-1} = x + 1 + \dfrac{1}{x-1}\). Comprobación: \((x+1)(x-1) + 1 = x^2\). \(\checkmark\) Derivando,

    \[f'(x) = 1 - \frac{1}{(x-1)^2} = \frac{(x-1)^2 - 1}{(x-1)^2} = \frac{x^2 - 2x}{(x-1)^2}.\]

    Coincide con la Parte 1. \(\checkmark\)

    Parte 3. \(f'(x) = 0\) si \(x = 0\) o \(x = 2\):

    \[f(0) = 0, \qquad f(2) = 4.\]

    En \(x = 3\): \(f(3) = \dfrac92\) y \(f'(3) = \dfrac{3\cdot 1}{4} = \dfrac34\), luego

    \[y = \frac92 + \frac34(x - 3) = \frac34\,x + \frac94.\]

    Solución

    \[f'(x) = \frac{x(x-2)}{(x-1)^2}, \quad \text{tangentes horizontales en } (0,0) \text{ y } (2,4), \quad y = \frac{3x+9}{4} \text{ en } x=3.\]

    Dos caminos

    La reescritura convierte un cociente en una suma y usa solo potencias. Cuando el grado del numerador es mayor o igual que el del denominador, dividir primero suele ser el camino más corto.

    Regla de la cadena

    Los ocho problemas siguientes se resuelven solo con la regla de la cadena (con las reglas básicas de potencias, exponencial y logaritmo como piezas): ni el producto ni el cociente son necesarios.

    Problema 11

    Derive cada función identificando primero la función exterior y la interior:

    1. \(f(x) = (3x - 2)^5\)
    2. \(g(x) = \sqrt{x^2 + 1}\)
    3. \(h(x) = \dfrac{1}{(2x+1)^3}\)
    4. \(k(x) = e^{-x^2}\)
    5. \(m(x) = \ln(3x^2 + 1)\)
    Ver desarrollo

    Método. En cada caso se escribe \(u\) como la función interior, se deriva la exterior respecto de \(u\) y se multiplica por \(u'\).

    Exterior Interior \(u\) Derivada
    1 \(u^5\) \(3x-2\) \(5(3x-2)^4\cdot 3 = 15(3x-2)^4\)
    2 \(\sqrt{u}\) \(x^2+1\) \(\dfrac{2x}{2\sqrt{x^2+1}} = \dfrac{x}{\sqrt{x^2+1}}\)
    3 \(u^{-3}\) \(2x+1\) \(-3(2x+1)^{-4}\cdot 2 = -\dfrac{6}{(2x+1)^4}\)
    4 \(e^{u}\) \(-x^2\) \(e^{-x^2}\cdot(-2x) = -2x\,e^{-x^2}\)
    5 \(\ln u\) \(3x^2+1\) \(\dfrac{6x}{3x^2+1}\)

    Solución

    \[f' = 15(3x-2)^4, \quad g' = \frac{x}{\sqrt{x^2+1}}, \quad h' = -\frac{6}{(2x+1)^4}, \quad k' = -2x\,e^{-x^2}, \quad m' = \frac{6x}{3x^2+1}.\]

    Un truco para no equivocarse

    Antes de derivar, pregúntese: "si tuviera que calcular esta función con una calculadora, ¿qué operación hago al final?". Esa es la función exterior. Lo que ya estaba calculado dentro es la interior.

    Problema 12

    Derive estas funciones, que combinan tres o más niveles de composición. Indique el dominio de cada derivada.

    1. \(f(x) = \sqrt{1 + \sqrt{x}}\)
    2. \(g(x) = \ln(\ln x)\)
    3. \(h(x) = e^{\sqrt{x}}\)
    4. \(k(x) = \big(1 + (x^2+1)^3\big)^4\)
    Ver desarrollo

    Método. Se derivan las capas de afuera hacia adentro, multiplicando las derivadas que se van obteniendo.

    1. Capas: \(\sqrt{\;\cdot\;}\) de \(1 + \sqrt{x}\), y esta última contiene \(\sqrt{x}\):

    \[f'(x) = \frac{1}{2\sqrt{1+\sqrt{x}}}\cdot\frac{1}{2\sqrt{x}} = \frac{1}{4\sqrt{x}\,\sqrt{1+\sqrt{x}}}, \qquad x > 0.\]

    2. Capas: \(\ln(\;\cdot\;)\) de \(\ln x\):

    \[g'(x) = \frac{1}{\ln x}\cdot\frac1x = \frac{1}{x\ln x}, \qquad x > 1.\]

    3. Capas: \(e^{(\;\cdot\;)}\) de \(\sqrt{x}\):

    \[h'(x) = e^{\sqrt{x}}\cdot\frac{1}{2\sqrt{x}} = \frac{e^{\sqrt{x}}}{2\sqrt{x}}, \qquad x > 0.\]

    4. Capas: \((\;\cdot\;)^4\) de \(1 + (x^2+1)^3\), que contiene \((\;\cdot\;)^3\) de \(x^2 + 1\):

    \[k'(x) = 4\big(1 + (x^2+1)^3\big)^3\cdot 3(x^2+1)^2\cdot 2x = 24x\,(x^2+1)^2\,\big(1 + (x^2+1)^3\big)^3.\]

    Solución

    \[f' = \frac{1}{4\sqrt{x}\sqrt{1+\sqrt{x}}}, \quad g' = \frac{1}{x\ln x}, \quad h' = \frac{e^{\sqrt{x}}}{2\sqrt{x}}, \quad k' = 24x\,(x^2+1)^2\big(1+(x^2+1)^3\big)^3.\]

    El dominio de \(g'\)

    \(\ln(\ln x)\) solo existe si \(\ln x > 0\), es decir \(x > 1\). En \(x=1\) el denominador \(x\ln x\) se anula, y a la izquierda de \(1\) el \(\ln x\) interior sería negativo: el dominio se obtiene siguiendo las capas desde adentro.

    Problema 13

    Derive, recordando que \((a^u)' = \ln(a)\,u'\,a^u\) y \((\log_a u)' = \dfrac{u'}{u\ln a}\):

    1. \(f(x) = 2^{x^2 - x}\)
    2. \(g(x) = \log_3(x^2 + 4)\)
    3. \(h(x) = \ln(e^{2x} + 1)\)
    4. \(k(x) = 5^{\sqrt{x}}\)
    Ver desarrollo

    1. Interior \(u = x^2 - x\), con \(u' = 2x - 1\):

    \[f'(x) = \ln 2\cdot(2x-1)\cdot 2^{x^2-x}.\]

    2. Interior \(u = x^2 + 4\), con \(u' = 2x\):

    \[g'(x) = \frac{2x}{(x^2+4)\ln 3}.\]

    3. Interior \(u = e^{2x} + 1\), y a su vez \((e^{2x})' = 2e^{2x}\):

    \[h'(x) = \frac{2e^{2x}}{e^{2x} + 1}.\]

    4. Interior \(u = \sqrt{x}\), con \(u' = \dfrac{1}{2\sqrt{x}}\):

    \[k'(x) = \ln 5\cdot\frac{1}{2\sqrt{x}}\cdot 5^{\sqrt{x}} = \frac{\ln 5\cdot 5^{\sqrt{x}}}{2\sqrt{x}}, \qquad x > 0.\]

    Solución

    \[f' = \ln 2\,(2x-1)\,2^{x^2-x}, \quad g' = \frac{2x}{(x^2+4)\ln 3}, \quad h' = \frac{2e^{2x}}{e^{2x}+1}, \quad k' = \frac{\ln 5\cdot 5^{\sqrt{x}}}{2\sqrt{x}}.\]

    Consistencia con \(e\)

    Cuando la base es \(e\), \(\ln e = 1\) y el factor logarítmico desaparece: la fórmula general se reduce a \((e^u)' = u'\,e^u\). Eso es lo que ocurre en el apartado 3.

    Problema 14

    Se conocen los siguientes valores de dos funciones derivables \(f\) y \(g\):

    \(x\) \(f(x)\) \(f'(x)\) \(g(x)\) \(g'(x)\)
    \(1\) \(2\) \(-3\) \(2\) \(6\)
    \(2\) \(4\) \(5\) \(1\) \(-2\)

    Calcule, sin conocer las fórmulas de \(f\) y \(g\):

    1. \((f\circ g)'(1)\)
    2. \((g\circ f)'(1)\)
    3. \((f\circ f)'(1)\)
    4. \(\big(f(x)^3\big)'\big|_{x=1}\)
    5. \(\left(\sqrt{f(x) + g(x)}\right)'\Big|_{x=1}\)
    Ver desarrollo

    Receta. \((f\circ g)'(a) = f'\big(g(a)\big)\cdot g'(a)\): hay que evaluar \(f'\) en \(g(a)\), no en \(a\).

    1. \(g(1) = 2\), luego \((f\circ g)'(1) = f'(2)\cdot g'(1) = 5\cdot 6 = 30\).

    2. \(f(1) = 2\), luego \((g\circ f)'(1) = g'(2)\cdot f'(1) = (-2)(-3) = 6\).

    3. \(f(1) = 2\), luego \((f\circ f)'(1) = f'(2)\cdot f'(1) = 5\cdot(-3) = -15\).

    4. Con exterior \(u^3\) e interior \(f(x)\):

    \[\big(f^3\big)'(1) = 3\,f(1)^2\,f'(1) = 3\cdot 4\cdot(-3) = -36.\]

    5. Aquí \(f(1) + g(1) = 4\) y \((f+g)'(1) = -3 + 6 = 3\):

    \[\left(\sqrt{f+g}\right)'(1) = \frac{(f+g)'(1)}{2\sqrt{f(1)+g(1)}} = \frac{3}{2\cdot 2} = \frac34.\]

    Solución

    \[(f\circ g)'(1) = 30, \quad (g\circ f)'(1) = 6, \quad (f\circ f)'(1) = -15, \quad \big(f^3\big)'(1) = -36, \quad \left(\sqrt{f+g}\right)'(1) = \frac34.\]

    Los dos primeros no son iguales

    \((f\circ g)'(1) = 30\) y \((g\circ f)'(1) = 6\): la composición no es conmutativa y tampoco lo son sus derivadas. El orden de las capas decide qué valor de la tabla hay que consultar.

    Problema 15

    Sea \(f(x) = \sqrt{x^2 + 16}\).

    1. Calcule \(f'(x)\).
    2. Encuentre la recta tangente en \(x = 3\).
    3. Encuentre la recta normal (la perpendicular a la tangente) en ese mismo punto.
    Ver desarrollo

    Parte 1. Exterior \(\sqrt{u}\), interior \(u = x^2 + 16\):

    \[f'(x) = \frac{2x}{2\sqrt{x^2+16}} = \frac{x}{\sqrt{x^2+16}}.\]

    Parte 2. \(f(3) = \sqrt{25} = 5\) y \(f'(3) = \dfrac35\). La tangente es

    \[y = 5 + \frac35(x - 3) = \frac35\,x + \frac{16}{5}.\]

    Parte 3. Dos rectas perpendiculares tienen pendientes cuyo producto es \(-1\), de modo que la pendiente de la normal es \(-\dfrac53\):

    \[y = 5 - \frac53(x - 3) = -\frac53\,x + 10.\]

    Solución

    \[f'(x) = \frac{x}{\sqrt{x^2+16}}, \qquad \text{tangente: } y = \frac{3x + 16}{5}, \qquad \text{normal: } y = -\frac{5x}{3} + 10.\]

    Verificación

    Ambas rectas pasan por \((3,5)\): \(\tfrac{9+16}{5} = 5\) y \(-5 + 10 = 5\). \(\checkmark\)

    Problema 16

    Encuentre el punto de la gráfica donde la recta tangente es horizontal, y determine su ordenada:

    1. \(g(x) = e^{-x^2 + 4x}\)
    2. \(h(x) = \ln\!\big(x^2 - 4x + 5\big)\)

    Justifique en (2) que \(h\) está definida en todo \(\mathbb{R}\).

    Ver desarrollo

    1. Interior \(u = -x^2 + 4x\), con \(u' = -2x + 4\):

    \[g'(x) = (4 - 2x)\,e^{-x^2+4x}.\]

    La exponencial nunca se anula, así que \(g'(x) = 0\) solo cuando \(4 - 2x = 0\), es decir \(x = 2\):

    \[g(2) = e^{-4+8} = e^4.\]

    2. Dominio: \(x^2 - 4x + 5 = (x-2)^2 + 1 \ge 1 > 0\) para todo \(x\), de modo que el logaritmo siempre existe. Interior \(u = x^2 - 4x + 5\):

    \[h'(x) = \frac{2x - 4}{x^2 - 4x + 5}.\]

    El denominador es positivo, así que \(h'(x) = 0\) solo si \(x = 2\):

    \[h(2) = \ln(1) = 0.\]

    Solución

    Para \(g\), la tangente es horizontal en \((2, e^4)\). Para \(h\), en \((2, 0)\).

    Un solo vértice para ambas

    En los dos casos el interior es una parábola con vértice en \(x=2\). Como \(e^u\) y \(\ln u\) son funciones crecientes, el máximo de \(g\) y el mínimo de \(h\) se alcanzan donde el interior alcanza su extremo: \(g\) tiene un máximo y \(h\) un mínimo en \(x=2\).

    Problema 17

    Un estudiante calculó las siguientes derivadas y cada una contiene un error. Identifique el error, explique qué regla se usó mal y corrija el resultado.

    1. \(\big(e^{3x}\big)' = 3x\,e^{3x-1}\)
    2. \(\big((x^2+1)^4\big)' = 4(x^2+1)^3\)
    3. \(\big(\sqrt{2x+1}\big)' = \dfrac{1}{2\sqrt{2x+1}}\)
    Ver desarrollo

    1. Confundió exponencial con potencia. Aplicó \((x^\alpha)' = \alpha x^{\alpha-1}\) con \(e^{3x}\) como si fuera una potencia, pero aquí el exponente es la variable. La regla correcta es \((e^u)' = u'\,e^u\) con \(u = 3x\):

    \[\big(e^{3x}\big)' = 3e^{3x}.\]

    2. Olvidó la derivada de la función interior. Derivó la exterior correctamente, pero no multiplicó por \((x^2+1)' = 2x\):

    \[\big((x^2+1)^4\big)' = 4(x^2+1)^3\cdot 2x = 8x\,(x^2+1)^3.\]

    3. Olvidó el factor de la interior. Aplicó \((\sqrt{u})' = \frac{1}{2\sqrt{u}}\) sin multiplicar por \(u' = 2\):

    \[\big(\sqrt{2x+1}\big)' = \frac{2}{2\sqrt{2x+1}} = \frac{1}{\sqrt{2x+1}}.\]

    Solución

    Error Resultado correcto
    1 Usó la regla de potencias en una exponencial \(3e^{3x}\)
    2 Omitió \(u' = 2x\) \(8x(x^2+1)^3\)
    3 Omitió \(u' = 2\) \(\dfrac{1}{\sqrt{2x+1}}\)

    Los tres comparten una raíz

    Cada error ocurre por no distinguir exterior de interior. Una comprobación rápida: si el argumento de la función no es simplemente \(x\), casi seguro hay un factor \(u'\) pendiente. Comparar con un valor numérico ayuda: con \(x=0\), el punto 2 daría \(0\) en la fórmula correcta y \(4\) en la incorrecta.

    Problema 18

    La regla de la cadena permite demostrar propiedades generales.

    1. Demuestre que si \(f\) es una función par y derivable (\(f(-x) = f(x)\) para todo \(x\)), entonces \(f'\) es impar (\(f'(-x) = -f'(x)\)).
    2. Verifique el resultado con \(f(x) = \ln(x^2+1)\).
    3. Demuestre de forma análoga que si \(f\) es impar y derivable, entonces \(f'\) es par, y compruébelo con \(g(x) = x^3\).
    Ver desarrollo

    Parte 1. Partimos de \(f(-x) = f(x)\) y derivamos ambos lados respecto de \(x\). En el lado izquierdo la función interior es \(-x\), cuya derivada es \(-1\):

    \[f'(-x)\cdot(-1) = f'(x) \implies f'(-x) = -f'(x).\]

    Es decir, \(f'\) es impar.

    Parte 2. \(f(x) = \ln(x^2+1)\) es par, porque \((-x)^2 = x^2\). Su derivada es

    \[f'(x) = \frac{2x}{x^2+1}, \qquad f'(-x) = \frac{-2x}{x^2+1} = -f'(x). \quad \checkmark\]

    Parte 3. Partimos de \(f(-x) = -f(x)\) y derivamos:

    \[f'(-x)\cdot(-1) = -f'(x) \implies f'(-x) = f'(x).\]

    Es decir, \(f'\) es par. Para \(g(x) = x^3\) (impar), \(g'(x) = 3x^2\) es par. \(\checkmark\)

    Solución

    Par \(\implies\) derivada impar, e impar \(\implies\) derivada par. En la demostración, el único ingrediente nuevo es la cadena aplicada a \(f(-x)\), que aporta el factor \(-1\).

    Interpretación geométrica

    Una gráfica par es simétrica respecto del eje \(y\): si la tangente sube hacia la derecha en \(x=a\), en \(x=-a\) baja con la pendiente opuesta. Por eso las pendientes cambian de signo y \(f'\) resulta impar.

    Problema 19

    Derive y simplifique:

    1. \(f(x) = x^2\sqrt{1 + x^2}\)
    2. \(g(x) = \dfrac{e^{2x}}{1 + e^{2x}}\)
    3. \(h(x) = \ln\!\big(x + \sqrt{x^2+1}\big)\)
    4. \(k(x) = \dfrac{x}{\sqrt{x^2+1}}\)
    Ver desarrollo

    1. Producto de \(x^2\) y \(\sqrt{1+x^2}\), y esta última requiere la cadena:

    \[f'(x) = 2x\sqrt{1+x^2} + x^2\cdot\frac{x}{\sqrt{1+x^2}} = \frac{2x(1+x^2) + x^3}{\sqrt{1+x^2}} = \frac{x\,(3x^2 + 2)}{\sqrt{1+x^2}}.\]

    2. Cociente, con \((e^{2x})' = 2e^{2x}\):

    \[g'(x) = \frac{2e^{2x}(1+e^{2x}) - e^{2x}\cdot 2e^{2x}}{(1+e^{2x})^2} = \frac{2e^{2x}}{(1+e^{2x})^2}.\]

    3. Cadena sobre el logaritmo. La derivada de la interior es \(1 + \dfrac{x}{\sqrt{x^2+1}} = \dfrac{\sqrt{x^2+1} + x}{\sqrt{x^2+1}}\), así que

    \[h'(x) = \frac{1}{x + \sqrt{x^2+1}}\cdot\frac{\sqrt{x^2+1} + x}{\sqrt{x^2+1}} = \frac{1}{\sqrt{x^2+1}}.\]

    4. Escribimos \(k(x) = x\,(x^2+1)^{-1/2}\) y aplicamos producto y cadena:

    \[k'(x) = (x^2+1)^{-1/2} - x^2\,(x^2+1)^{-3/2} = \frac{(x^2+1) - x^2}{(x^2+1)^{3/2}} = \frac{1}{(x^2+1)^{3/2}}.\]

    Solución

    \[f' = \frac{x(3x^2+2)}{\sqrt{1+x^2}}, \quad g' = \frac{2e^{2x}}{(1+e^{2x})^2}, \quad h' = \frac{1}{\sqrt{x^2+1}}, \quad k' = \frac{1}{(x^2+1)^{3/2}}.\]

    Simplificaciones que sorprenden

    En el apartado 3 una expresión de aspecto complicado colapsa a \(\frac{1}{\sqrt{x^2+1}}\): el factor \(x + \sqrt{x^2+1}\) aparece tanto en el denominador como, "escondido", en el numerador. Conviene desconfiar de un resultado enrevesado y buscar un factor común.

    Problema 20

    Use propiedades de los logaritmos para simplificar antes de derivar. Indique el dominio de cada función.

    1. \(f(x) = \ln\dfrac{(x+1)^2}{x-1}\)
    2. \(g(x) = \ln\sqrt{\dfrac{1+x}{1-x}}\)
    3. \(h(x) = \ln\!\big(x\,e^{x^2}\big)\)
    Ver desarrollo

    1. Dominio: \(\dfrac{(x+1)^2}{x-1} > 0 \iff x > 1\). Con esa restricción,

    \[f(x) = 2\ln(x+1) - \ln(x-1) \implies f'(x) = \frac{2}{x+1} - \frac{1}{x-1} = \frac{2(x-1) - (x+1)}{x^2-1} = \frac{x-3}{x^2-1}.\]

    2. Dominio: \(\dfrac{1+x}{1-x} > 0 \iff -1 < x < 1\). Con esa restricción,

    \[g(x) = \tfrac12\big[\ln(1+x) - \ln(1-x)\big] \implies g'(x) = \tfrac12\left[\frac{1}{1+x} + \frac{1}{1-x}\right] = \frac{1}{1-x^2}.\]

    3. Dominio: \(x\,e^{x^2} > 0 \iff x > 0\). Con esa restricción,

    \[h(x) = \ln x + x^2 \implies h'(x) = \frac1x + 2x.\]

    Solución

    \[f'(x) = \frac{x-3}{x^2-1}\;\; (x>1), \qquad g'(x) = \frac{1}{1-x^2}\;\; (|x|<1), \qquad h'(x) = \frac1x + 2x\;\; (x>0).\]

    Cuidado con el dominio

    Las propiedades \(\ln(ab) = \ln a + \ln b\) y \(\ln\frac ab = \ln a - \ln b\) solo valen si \(a\) y \(b\) son positivos. En el apartado 1, por ejemplo, la expresión original está definida también para algunos \(x<-1\), pero la versión simplificada con \(\ln(x-1)\) no. Por eso se declara el dominio antes de transformar.

    Problema 21

    DERIVACIÓN LOGARÍTMICA. Las funciones con base y exponente variables no se derivan con las reglas de potencia ni de exponencial. El truco es aplicar \(\ln\) a ambos lados y derivar de forma implícita.

    1. Derive \(f(x) = x^x\), para \(x > 0\).
    2. Derive \(g(x) = x^{1/x}\), para \(x > 0\), y encuentre el punto con tangente horizontal.
    Ver desarrollo

    Parte 1. Tomamos logaritmo: \(\ln f(x) = x\ln x\). Derivamos ambos lados; a la izquierda se usa la cadena, \(\dfrac{f'(x)}{f(x)}\):

    \[\frac{f'(x)}{f(x)} = \ln x + x\cdot\frac1x = \ln x + 1 \implies f'(x) = x^x\,(\ln x + 1).\]

    Parte 2. Tomamos logaritmo: \(\ln g(x) = \dfrac{\ln x}{x}\). Derivando con la regla del cociente:

    \[\frac{g'(x)}{g(x)} = \frac{\frac1x\cdot x - \ln x\cdot 1}{x^2} = \frac{1 - \ln x}{x^2} \implies g'(x) = x^{1/x}\cdot\frac{1 - \ln x}{x^2}.\]

    Tangente horizontal. Como \(x^{1/x} > 0\) y \(x^2 > 0\), se anula solo cuando \(1 - \ln x = 0\), es decir \(x = e\):

    \[g(e) = e^{1/e} \approx 1{,}44.\]

    Solución

    \[f'(x) = x^x(\ln x + 1), \qquad g'(x) = x^{1/x}\,\frac{1-\ln x}{x^2},\]

    y \(g\) tiene tangente horizontal en \(\left(e,\,e^{1/e}\right)\).

    Un resultado curioso

    Para \(x>e\) se tiene \(1 - \ln x < 0\) y \(g\) decrece; para \(0<x<e\) crece. Luego \(e^{1/e}\) es el máximo de \(x^{1/x}\) sobre los reales positivos. Entre los números enteros, el máximo de \(n^{1/n}\) se alcanza en \(n=3\), el entero más cercano a \(e\).

    Problema 22

    ENFRIAMIENTO. Una taza de té se deja enfriar en una habitación a \(20\,^\circ\text{C}\). Su temperatura \(t\) minutos después es

    \[T(t) = 20 + 60\,e^{-0{,}1\,t} \quad (^\circ\text{C}).\]
    1. Calcule \(T'(t)\) y la rapidez de enfriamiento inicial, \(T'(0)\), con sus unidades.
    2. Demuestre que \(T'(t) = -0{,}1\,\big(T(t) - 20\big)\) y explique qué dice esa relación.
    3. ¿En qué instante la temperatura baja a razón de \(3\,^\circ\text{C}\) por minuto, y cuál es entonces la temperatura?
    Ver desarrollo

    Parte 1. Con la cadena, \((e^{-0{,}1t})' = -0{,}1\,e^{-0{,}1t}\):

    \[T'(t) = 60\cdot(-0{,}1)\,e^{-0{,}1t} = -6\,e^{-0{,}1t}.\]

    En \(t = 0\): \(T'(0) = -6\,^\circ\text{C}/\text{min}\). El té se enfría inicialmente a \(6\) grados por minuto.

    Parte 2. Como \(T(t) - 20 = 60\,e^{-0{,}1t}\),

    \[-0{,}1\,\big(T(t) - 20\big) = -0{,}1\cdot 60\,e^{-0{,}1t} = -6\,e^{-0{,}1t} = T'(t). \quad \checkmark\]

    Esto es la ley de enfriamiento de Newton: la rapidez de enfriamiento es proporcional a la diferencia entre la temperatura del objeto y la del ambiente. Cuanto más caliente está el té respecto de la habitación, más rápido se enfría.

    Parte 3. Resolvemos \(T'(t) = -3\):

    \[-6\,e^{-0{,}1t} = -3 \implies e^{-0{,}1t} = \tfrac12 \implies -0{,}1\,t = -\ln 2 \implies t = 10\ln 2 \approx 6{,}93 \text{ min}.\]

    La temperatura en ese instante es \(T = 20 + 60\cdot\tfrac12 = 50\,^\circ\text{C}\).

    Solución

    \[T'(t) = -6\,e^{-0{,}1t}, \qquad T'(0) = -6\,^\circ\text{C/min}, \qquad t = 10\ln 2 \approx 6{,}93 \text{ min}, \quad T = 50\,^\circ\text{C}.\]

    Verificación con la relación de Newton

    A \(50\,^\circ\text{C}\): \(-0{,}1\,(50 - 20) = -3\). \(\checkmark\) La rapidez de enfriamiento se reduce a la mitad exactamente cuando el exceso de temperatura se reduce a la mitad (de \(60\) a \(30\)).

    Problema 23

    INGRESO. Cuando se venden \(q\) unidades de un producto, el precio unitario es \(p(q) = 200\,e^{-q/50}\) miles de pesos.

    1. Escriba el ingreso total \(R(q) = q\,p(q)\) y calcule el ingreso marginal \(R'(q)\).
    2. ¿Para qué nivel de ventas el ingreso marginal es cero? ¿Qué signo tiene antes y después?
    3. Calcule el ingreso máximo.
    Ver desarrollo

    Parte 1. El ingreso es \(R(q) = 200\,q\,e^{-q/50}\). Producto de \(q\) y \(e^{-q/50}\), con \((e^{-q/50})' = -\tfrac{1}{50}e^{-q/50}\):

    \[R'(q) = 200\,e^{-q/50} + 200\,q\left(-\frac{1}{50}\right)e^{-q/50} = 200\,e^{-q/50}\left(1 - \frac{q}{50}\right) = 4\,(50 - q)\,e^{-q/50}.\]

    Parte 2. La exponencial es positiva, así que el signo lo decide \(50 - q\):

    Intervalo \([0, 50[\) \(]50, +\infty[\)
    \(R'(q)\) \(\boldsymbol{+}\) \(-\)

    Se anula en \(q = 50\).

    Parte 3. El ingreso máximo se alcanza en \(q = 50\):

    \[R(50) = 200\cdot 50\,e^{-1} = \frac{10\,000}{e} \approx 3\,678{,}8 \text{ miles de pesos}.\]

    Solución

    \[R'(q) = 4(50 - q)\,e^{-q/50}, \qquad \text{máximo en } q = 50, \qquad R(50) = \frac{10\,000}{e} \approx 3\,679 \text{ miles de pesos}.\]

    Qué significa

    Hasta \(50\) unidades, vender una unidad más aumenta el ingreso. Después de \(50\), el precio cae tan rápido que el ingreso total disminuye, aunque se venda más. El ingreso marginal negativo es una señal de alerta: producir más ya no conviene.

    Problema 24

    GLOBO. Un globo esférico se infla de modo que su radio, en centímetros, crece con el tiempo según \(r(t) = 2 + 0{,}5\,t\) (\(t\) en segundos). El volumen es \(V = \tfrac43\pi r^3\).

    1. Calcule \(\dfrac{dV}{dr}\) e identifique qué cantidad geométrica es.
    2. Exprese \(V\) como función de \(t\) y calcule \(V'(t)\) con la regla de la cadena.
    3. Calcule la rapidez con que crece el volumen en \(t = 2\) s.
    Ver desarrollo

    Parte 1.

    \[\frac{dV}{dr} = 4\pi r^2,\]

    que es el área de la superficie de la esfera. Tiene sentido: una capa muy delgada de espesor \(\Delta r\) agrega un volumen aproximado de \(4\pi r^2\cdot\Delta r\).

    Parte 2. \(V(t) = \tfrac43\pi\,(2 + 0{,}5t)^3\). Con la cadena, la derivada de la interior es \(0{,}5\):

    \[V'(t) = \tfrac43\pi\cdot 3\,(2 + 0{,}5t)^2\cdot 0{,}5 = 2\pi\,(2 + 0{,}5\,t)^2.\]

    Es lo mismo que \(\dfrac{dV}{dr}\cdot\dfrac{dr}{dt} = 4\pi r^2\cdot 0{,}5\).

    Parte 3. En \(t = 2\) se tiene \(r = 3\), luego

    \[V'(2) = 2\pi\cdot 3^2 = 18\pi \approx 56{,}5 \text{ cm}^3/\text{s}.\]

    Solución

    \[\frac{dV}{dr} = 4\pi r^2, \qquad V'(t) = 2\pi\,(2 + 0{,}5\,t)^2, \qquad V'(2) = 18\pi \approx 56{,}5\ \text{cm}^3/\text{s}.\]

    La cadena como lenguaje de razones de cambio

    \(\dfrac{dV}{dt} = \dfrac{dV}{dr}\cdot\dfrac{dr}{dt}\) dice que la rapidez con que cambia el volumen es la rapidez de cambio del volumen respecto del radio por la rapidez con que cambia el radio. Aunque \(r'(t)=0{,}5\) es constante, \(V'(t)\) crece: una misma variación de radio agrega cada vez más volumen.

    Problema 25

    Determine las constantes \(a\) y \(b\) para que la parábola \(f(x) = x^2 + ax + b\) y la hipérbola \(g(x) = \dfrac{1}{x}\) sean tangentes en el punto de abscisa \(x = 1\), es decir, que se toquen en ese punto con la misma recta tangente. Escriba la ecuación de esa recta.

    Qué significa "tangentes en \(x=1\)". Dos curvas son tangentes en un punto si ambas condiciones se cumplen a la vez:

    1. Pasan por el mismo punto: \(f(1) = g(1)\).
    2. Tienen la misma pendiente: \(f'(1) = g'(1)\).

    Datos de \(g\). \(g(1) = 1\) y \(g'(x) = -\dfrac{1}{x^2}\), luego \(g'(1) = -1\).

    Datos de \(f\). \(f(1) = 1 + a + b\) y \(f'(x) = 2x + a\), luego \(f'(1) = 2 + a\).

    Sistema.

    \[\begin{cases} 1 + a + b = 1 \\ 2 + a = -1 \end{cases} \implies a = -3, \quad b = 3.\]

    Recta tangente común. Pasa por \((1,1)\) con pendiente \(-1\):

    \[y = 1 - (x - 1) = 2 - x.\]

    Solución

    \[a = -3, \qquad b = 3, \qquad f(x) = x^2 - 3x + 3, \qquad \text{tangente común: } y = 2 - x.\]

    Verificación

    \(f(1) = 1 - 3 + 3 = 1 = g(1)\). \(\checkmark\) \(\;f'(1) = 2 - 3 = -1 = g'(1)\). \(\checkmark\) La condición de "pasar por el mismo punto" por sí sola no basta: infinitas parábolas cortan a \(g\) en \((1,1)\), pero solo una lo hace con la misma pendiente.
