    Desigualdades y propiedades de orden

    Análisis de proposiciones, contraejemplos y aplicación de las propiedades de orden en \(\mathbb{R}\).

    Propiedades de orden en \(\mathbb{R}\)

    Sean \(a, b, c, d \in \mathbb{R}\).

    Propiedad Enunciado
    O1 Tricotomía Se cumple exactamente una: \(a < b\), \(a = b\) o \(a > b\).
    O2 Transitividad Si \(a < b\) y \(b < c\), entonces \(a < c\).
    O3 Compatibilidad con la suma Si \(a < b\), entonces \(a + c < b + c\) para todo \(c \in \mathbb{R}\).
    O4 Compatibilidad con el producto Si \(a < b\) y \(c > 0\), entonces \(ac < bc\). Si \(a < b\) y \(c < 0\), entonces \(ac > bc\).

    Consecuencias de uso frecuente:

    • Suma de desigualdades: si \(a < b\) y \(c < d\), entonces \(a + c < b + d\).
    • Cuadrados: \(a^2 \ge 0\) para todo \(a\), con igualdad solo si \(a = 0\).
    • Cuadrados y orden: si \(0 \le a < b\), entonces \(a^2 < b^2\). La hipótesis \(0 \le a\) es indispensable.
    • Recíprocos: si \(0 < a < b\), entonces \(\dfrac{1}{b} < \dfrac{1}{a}\). De nuevo, ambos deben ser positivos.
    • Valor absoluto: \(|x| < b \iff -b < x < b\), y \(|x| > b \iff x < -b \;\text{o}\; x > b\) (con \(b > 0\)).

    Las dos trampas de esta sección

    1. Multiplicar o dividir por algo de signo desconocido. Si la expresión contiene la variable, su signo no se conoce y no se puede decidir si la desigualdad se conserva o se invierte.
    2. Elevar al cuadrado o tomar recíprocos sin restringir el signo. Casi todas las propiedades sobre cuadrados y recíprocos exigen positividad; al olvidarla, los números negativos producen contraejemplos inmediatos.

    Verdadero o falso

    Determine si las siguientes proposiciones son verdaderas o falsas. Justifique debidamente proporcionando una demostración o un contraejemplo.

    Problema 1 { #prop-01 }

    Sea \(a \in \mathbb{R}\). Si \(x^2 \le a^2\), entonces \(x \le a\).

    Ver solución

    Falso

    Contraejemplo: \(a = -5\), \(x = 2\).

    Verificamos que la hipótesis se cumple y la conclusión no:

    Valor ¿Se cumple?
    Hipótesis: \(x^2 \le a^2\) \(4 \le 25\) Sí
    Conclusión: \(x \le a\) \(2 \le -5\) No

    El problema está en que la función \(t \mapsto t^2\) no preserva el orden en toda la recta: lo hace solo sobre los reales no negativos. Al elevar al cuadrado se pierde la información del signo, y lo único que queda es la distancia al origen.

    Enunciado corregido

    Si \(x^2 \le a^2\), entonces \(|x| \le |a|\), lo que equivale a \(-|a| \le x \le |a|\).

    Problema 2 { #prop-02 }

    Si \(x(x-1) > 5\), entonces \(x > 5\) y \(x - 1 > 5\).

    Ver solución

    Falso

    Contraejemplo: \(x = -3\).

    En efecto, \(x(x-1) = (-3)(-4) = 12 > 5\), de modo que la hipótesis se cumple; sin embargo, \(-3 > 5\) es falso.

    El error consiste en trasladar a las desigualdades un razonamiento válido solo para el caso \(AB = 0\). Que un producto supere a \(5\) no obliga a ningún factor en particular a superar a \(5\): el producto de dos números negativos es positivo y puede ser tan grande como se quiera.

    Enunciado corregido

    De \(x(x-1) > 5\) se sigue \(x^2 - x - 5 > 0\), cuyas raíces son \(\dfrac{1 \pm \sqrt{21}}{2}\). La solución es

    \[S = \left]-\infty, \dfrac{1-\sqrt{21}}{2}\right[ \,\cup\, \left]\dfrac{1+\sqrt{21}}{2}, +\infty\right[,\]

    es decir, dos intervalos, no uno.

    Problema 3 { #prop-03 }

    La inecuación \(\dfrac{x}{p} > 1\) es equivalente a \(x > p\).

    Ver solución

    Falso

    Contraejemplo: \(p = -2\), \(x = -4\).

    Con esos valores, \(\dfrac{x}{p} = \dfrac{-4}{-2} = 2 > 1\), pero \(x > p\) significa \(-4 > -2\), que es falso.

    La equivalencia depende por completo del signo de \(p\), y hay que distinguir tres casos:

    Caso Al multiplicar por \(p\) Equivalente a
    \(p > 0\) La desigualdad se conserva (O4) \(x > p\)
    \(p < 0\) La desigualdad se invierte (O4) \(x < p\)
    \(p = 0\) No se puede multiplicar La expresión no está definida

    Enunciado corregido

    La equivalencia \(\dfrac{x}{p} > 1 \iff x > p\) es válida si y solo si \(p > 0\).

    Problema 4 { #prop-04 }

    Sea \(x \in \mathbb{R}\). Si \(x^2 > x\), entonces necesariamente \(x > 1\).

    Ver solución

    Falso

    Contraejemplo: \(x = -2\).

    Se tiene \((-2)^2 = 4 > -2\), de modo que la hipótesis se cumple, pero \(-2 > 1\) es falso.

    El origen del error es "cancelar" una \(x\) a ambos lados de \(x^2 > x\), operación que equivale a dividir por \(x\) sin conocer su signo. El procedimiento correcto es factorizar:

    \[x^2 - x > 0 \implies x(x-1) > 0,\]

    producto que es positivo cuando ambos factores son positivos o cuando ambos son negativos.

    Enunciado corregido

    \(x^2 > x \iff x \in \;]-\infty, 0[ \,\cup\, ]1, +\infty[\).

    Problema 5 { #prop-05 }

    Para todo \(a, b \in \mathbb{R}\): si \(a < b\), entonces \(a^2 < b^2\).

    Ver solución

    Falso

    Contraejemplo: \(a = -10\), \(b = 2\).

    Valor ¿Se cumple?
    Hipótesis: \(a < b\) \(-10 < 2\) Sí
    Conclusión: \(a^2 < b^2\) \(100 < 4\) No

    La propiedad O4 permite multiplicar \(a < b\) por un número positivo. Para obtener \(a^2 < b^2\) habría que multiplicar la desigualdad por \(a\) y por \(b\) respectivamente, lo que requiere que ambos sean positivos. Si \(a\) es negativo, el paso se invierte.

    Enunciado corregido

    Si \(0 \le a < b\), entonces \(a^2 < b^2\). En general, para \(a < b\) cualesquiera solo se puede afirmar \(a^2 < b^2\) cuando \(|a| < |b|\).

    Problema 6 { #prop-06 }

    La desigualdad \(|x - 3| < 5\) es equivalente a \(-2 < x < 8\).

    Ver solución

    Verdadero

    Ambas expresiones describen el mismo conjunto: los puntos que distan de \(3\) menos de \(5\) unidades.

    Aplicamos la caracterización del valor absoluto y luego O3, sumando \(3\) a los tres miembros:

    \[|x-3| < 5 \iff -5 < x - 3 < 5 \iff -5 + 3 < x < 5 + 3 \iff -2 < x < 8.\]

    Todos los pasos son equivalencias, ya que O3 vale para todo \(c\) y es reversible (se puede restar \(3\) para volver atrás). No hubo multiplicaciones por cantidades de signo desconocido, que es donde suelen romperse estas cadenas.

    Geométricamente: el intervalo \(]-2, 8[\) está centrado en \(3\) y tiene radio \(5\).

    Problema 7 { #prop-07 }

    Si \(x < 2\), entonces \(\dfrac{1}{x} > \dfrac{1}{2}\).

    Ver solución

    Falso

    Contraejemplo: \(x = -1\).

    Es cierto que \(-1 < 2\), pero \(\dfrac{1}{-1} = -1\) no es mayor que \(\dfrac{1}{2}\).

    La propiedad "tomar recíprocos invierte el orden" exige que ambos números sean del mismo signo. Aquí \(x\) puede ser negativo, y al cruzar el cero la función \(t \mapsto 1/t\) salta de valores muy negativos a valores muy positivos. Note, además, que el enunciado ni siquiera tiene sentido para \(x = 0\), valor que sí satisface \(x < 2\).

    Enunciado corregido

    Si \(0 < x < 2\), entonces \(\dfrac{1}{x} > \dfrac{1}{2}\).

    Aplicación de propiedades de orden

    En esta sección no se pide decidir un valor de verdad, sino usar las propiedades: justificar pasos, detectar dónde se rompe un argumento, acotar expresiones y demostrar desigualdades.

    Problema 8 { #prop-08 }

    Sean \(a, b, c, d \in \mathbb{R}\) tales que \(a < b\) y \(c < d\).

    1. Justifique cada paso de la cadena \(a + c < b + c < b + d\), indicando qué propiedad se usa.
    2. Decida si de las mismas hipótesis se puede concluir que \(a - c < b - d\).
    Ver solución

    Parte 1. Cada desigualdad se obtiene de O3, sumando una misma cantidad a ambos lados:

    Paso De Se obtiene Propiedad
    1 \(a < b\) \(a + c < b + c\) O3, sumando \(c\)
    2 \(c < d\) \(b + c < b + d\) O3, sumando \(b\)
    3 \(a+c < b+c\) y \(b+c < b+d\) \(a + c < b + d\) O2, transitividad

    Esto demuestra la regla general: las desigualdades del mismo sentido se pueden sumar.

    Parte 2: no se puede

    Contraejemplo: \(a = 0\), \(b = 1\), \(c = 0\), \(d = 10\).

    Las hipótesis se cumplen (\(0 < 1\) y \(0 < 10\)), pero \(a - c = 0\) mientras que \(b - d = -9\), y \(0 < -9\) es falso.

    La razón es que de \(c < d\) se sigue \(-d < -c\) (multiplicando por \(-1\), con inversión por O4), es decir, la desigualdad en \(-c\) y \(-d\) apunta al revés que la de \(a\) y \(b\). Al no ir en el mismo sentido, no se pueden sumar.

    Regla correcta

    Las desigualdades se suman cuando van en el mismo sentido; para restar hay que invertir primero una de ellas: de \(a < b\) y \(c < d\) se concluye \(a - d < b - c\).

    Problema 9 { #prop-09 }

    En cada uno de los siguientes argumentos hay exactamente un paso incorrecto. Identifíquelo, explique qué propiedad se invocó mal y entregue la conclusión correcta.

    1. Como \(-6 < -2\), al dividir ambos lados por \(-2\) se obtiene \(3 < 1\).
    2. Para resolver \(\dfrac{1}{x} < 1\), multiplicamos ambos lados por \(x\) y obtenemos \(1 < x\); por lo tanto, \(S = \,]1, +\infty[\).
    Ver solución

    Argumento 1: el error está en la división

    Se dividió por \(-2\), que es negativo, conservando el sentido de la desigualdad.

    La propiedad O4 establece que al multiplicar o dividir por una cantidad negativa la desigualdad se invierte. Lo correcto es:

    \[-6 < -2 \implies \dfrac{-6}{-2} > \dfrac{-2}{-2} \implies 3 > 1,\]

    que sí es verdadero.

    Argumento 2: el error está en la multiplicación

    Se multiplicó por \(x\), cuyo signo es desconocido.

    Si \(x\) fuera negativo, la desigualdad debería invertirse; como no sabemos su signo, el paso es inválido. Al asumir implícitamente \(x > 0\), el argumento pierde todas las soluciones negativas. El procedimiento correcto es llevar todo a un lado:

    \[\dfrac{1}{x} - 1 < 0 \implies \dfrac{1-x}{x} < 0.\]

    Los puntos críticos son \(x = 1\) (numerador) y \(x = 0\) (denominador):

    Factor \(]-\infty,0[\) \(]0,1[\) \(]1,+\infty[\)
    \(1-x\) \(+\) \(+\) \(-\)
    \(x\) \(-\) \(+\) \(+\)
    Cociente \(\boldsymbol{-}\) \(+\) \(\boldsymbol{-}\)
    \[S = \;]-\infty, 0[ \,\cup\, ]1, +\infty[.\]

    El intervalo \(]-\infty, 0[\) es precisamente lo que el argumento original había extraviado.

    Problema 10 { #prop-10 }

    Sean \(x, y \in \mathbb{R}\) tales que \(2 < x < 5\) y \(-1 < y < 3\). Determine el intervalo más pequeño que con certeza contiene a cada una de las expresiones \(x+y\), \(x-y\) y \(xy\).

    Ver solución

    Para \(x + y\). Sumamos las dos desigualdades, que van en el mismo sentido:

    \[2 + (-1) < x + y < 5 + 3 \implies 1 < x + y < 8.\]

    Para \(x - y\). No se pueden restar directamente. Primero invertimos la desigualdad de \(y\) multiplicando por \(-1\) (O4):

    \[-1 < y < 3 \implies -3 < -y < 1.\]

    Ahora sí sumamos:

    \[2 + (-3) < x - y < 5 + 1 \implies -1 < x - y < 6.\]

    Para \(xy\). Aquí no hay una regla de suma que aplicar, porque \(y\) cambia de signo dentro de su intervalo. Como \(x\) es positivo, el producto \(xy\) crece con \(y\), de modo que basta examinar las cuatro combinaciones de extremos y quedarse con el mínimo y el máximo:

    \(y \to -1\) \(y \to 3\)
    \(x \to 2\) \(-2\) \(6\)
    \(x \to 5\) \(\boldsymbol{-5}\) \(\boldsymbol{15}\)
    \[-5 < xy < 15.\]

    Advertencia sobre el cociente

    Sería natural intentar acotar también \(\dfrac{x}{y}\), pero no se puede: el valor \(y = 0\) pertenece al intervalo \(]-1, 3[\), y en sus cercanías el cociente crece sin cota, tanto hacia \(+\infty\) como hacia \(-\infty\). Ningún intervalo acotado lo contiene.

    Problema 11 { #prop-11 }

    Demuestre que para todo \(a > 0\) se cumple

    \[a + \dfrac{1}{a} \ge 2,\]

    e indique para qué valor de \(a\) se alcanza la igualdad.

    Ver solución

    La estrategia estándar consiste en partir de una desigualdad que sea verdadera siempre y transformarla hasta llegar a la que se pide. El punto de partida natural es que todo cuadrado es no negativo:

    \[(a-1)^2 \ge 0.\]

    Expandimos:

    \[a^2 - 2a + 1 \ge 0.\]

    Ahora dividimos ambos lados por \(a\). Este paso es legítimo porque la hipótesis garantiza \(a > 0\), de modo que la desigualdad conserva su sentido (O4):

    \[\dfrac{a^2 - 2a + 1}{a} \ge 0 \implies a - 2 + \dfrac{1}{a} \ge 0.\]

    Finalmente, sumamos \(2\) a ambos lados (O3):

    \[a + \dfrac{1}{a} \ge 2. \qquad \blacksquare\]

    Caso de igualdad. Todos los pasos son equivalencias, así que la igualdad se alcanza exactamente cuando \((a-1)^2 = 0\), es decir, cuando \(a = 1\). En efecto, \(1 + \dfrac{1}{1} = 2\).

    La hipótesis \(a > 0\) no es decorativa

    Si \(a < 0\), la división invierte la desigualdad y el resultado es el opuesto: \(a + \dfrac{1}{a} \le -2\). Por ejemplo, con \(a = -1\) se obtiene \(-2\), que es mucho menor que \(2\).

    Problema 12 { #prop-12 }

    Determine todos los valores de \(k \in \mathbb{R}\) para los cuales la implicación

    \[x < 3 \implies kx < 3k\]

    es verdadera para todo \(x \in \mathbb{R}\).

    Ver solución

    La conclusión \(kx < 3k\) es exactamente lo que se obtiene al multiplicar la hipótesis \(x < 3\) por \(k\) conservando el sentido. Según O4, eso ocurre si y solo si \(k\) es positivo. Revisemos los tres casos:

    Caso Qué produce O4 ¿Coincide con \(kx < 3k\)?
    \(k > 0\) \(kx < 3k\) Sí
    \(k = 0\) \(0 = 0\) No: exigiría \(0 < 0\)
    \(k < 0\) \(kx > 3k\) No: el sentido es el opuesto

    El caso \(k = 0\) merece atención, porque es el que más se escapa: al multiplicar por cero ambos lados se vuelven \(0\), y la desigualdad estricta \(0 < 0\) es falsa. Por lo tanto \(k = 0\) no sirve.

    Para \(k < 0\) basta un contraejemplo: con \(k = -1\) y \(x = 0\) se cumple \(x < 3\), pero \(kx = 0\) y \(3k = -3\), de modo que \(0 < -3\) es falso.

    \[\boxed{\,k \in \;]0, +\infty[\,}\]

    Variante

    Si la implicación fuera \(x < 3 \implies kx \le 3k\), la respuesta incluiría a \(k=0\), quedando \(k \ge 0\).

    Problema 13 { #prop-13 }

    Suponga que \(|x - 2| < 1\). Demuestre que:

    1. \(\dfrac{1}{|x+1|} < \dfrac{1}{2}\);
    2. \(\left| \dfrac{1}{x+1} - \dfrac{1}{3} \right| < \dfrac{|x-2|}{6}\).
    Ver solución

    Parte 1. Traducimos la hipótesis a un intervalo y lo desplazamos hasta obtener información sobre \(x+1\):

    \[|x-2| < 1 \iff -1 < x - 2 < 1 \iff 1 < x < 3.\]

    Sumando \(1\) a los tres miembros (O3):

    \[2 < x + 1 < 4.\]

    En particular \(x + 1 > 0\), de modo que \(|x+1| = x+1 > 2\). Como ambos lados son positivos, podemos tomar recíprocos invirtiendo el sentido:

    \[\dfrac{1}{|x+1|} < \dfrac{1}{2}. \qquad \blacksquare\]

    Parte 2. Reducimos la diferencia a una sola fracción:

    \[\dfrac{1}{x+1} - \dfrac{1}{3} = \dfrac{3 - (x+1)}{3(x+1)} = \dfrac{2-x}{3(x+1)}.\]

    Tomando valor absoluto y usando que \(|2-x| = |x-2|\):

    \[\left| \dfrac{1}{x+1} - \dfrac{1}{3} \right| = \dfrac{|x-2|}{3\,|x+1|} = \dfrac{|x-2|}{3} \cdot \dfrac{1}{|x+1|}.\]

    Por la parte 1, el segundo factor es menor que \(\dfrac{1}{2}\), y como \(\dfrac{|x-2|}{3} \ge 0\), al multiplicar se preserva la desigualdad:

    \[\left| \dfrac{1}{x+1} - \dfrac{1}{3} \right| < \dfrac{|x-2|}{3} \cdot \dfrac{1}{2} = \dfrac{|x-2|}{6}. \qquad \blacksquare\]

    Por qué importa esta técnica

    Acotar un factor "molesto" por una constante para dejar el resto controlado por \(|x-2|\) es exactamente el mecanismo que se usa en las demostraciones de límites con \(\varepsilon\)–\(\delta\). La hipótesis \(|x-2|<1\) cumple ahí el papel de restricción auxiliar sobre \(\delta\).

    Problema 14 { #prop-14 }

    Sean \(a, b \in \mathbb{R}\) con \(0 < a < b\). Demuestre la cadena de desigualdades

    \[a < \dfrac{2ab}{a+b} < \dfrac{a+b}{2} < b.\]
    Ver solución

    Las tres expresiones centrales son, de izquierda a derecha, la media armónica y la media aritmética de \(a\) y \(b\). Observemos primero que \(a + b > 0\), lo que permitirá multiplicar por \(a+b\) sin invertir nada.

    Primera desigualdad: \(a < \dfrac{2ab}{a+b}\).

    Multiplicamos por \(a + b > 0\) (O4, se conserva el sentido):

    \[a(a+b) < 2ab \iff a^2 + ab < 2ab \iff a^2 < ab.\]

    Dividiendo por \(a > 0\), esto equivale a \(a < b\), que es la hipótesis.

    Segunda desigualdad: \(\dfrac{2ab}{a+b} < \dfrac{a+b}{2}\).

    Multiplicamos en cruz por \(2(a+b) > 0\):

    \[4ab < (a+b)^2 \iff 0 < a^2 - 2ab + b^2 \iff 0 < (a-b)^2.\]

    Esto es verdadero, ya que todo cuadrado es no negativo y aquí \(a \ne b\) garantiza que no se anula.

    Tercera desigualdad: \(\dfrac{a+b}{2} < b\).

    Multiplicando por \(2 > 0\): \(a + b < 2b\), y restando \(b\) (O3) queda \(a < b\), la hipótesis.

    Encadenando las tres por transitividad (O2) se obtiene el resultado. \(\blacksquare\)

    Verificación numérica

    Con \(a = 2\) y \(b = 8\):

    \[2 < \dfrac{2 \cdot 2 \cdot 8}{10} = 3{,}2 < \dfrac{10}{2} = 5 < 8. \quad \checkmark\]

    Observación

    La igualdad en toda la cadena se alcanzaría únicamente si \(a = b\), caso excluido por hipótesis. Entre ambas medias se puede intercalar además la media geométrica \(\sqrt{ab}\).
